## 案例 1：吃醋女友质问

**场景：** 校园恋爱，女友发现男友和别的女生吃饭，当场质问  
**角色语气：** 强势、醋意、理直气壮、霸道  
**语言特点：** 半语，校园口语，情绪递进

| 中文 | 韩语 |
|---|---|
| **标题** | **标题** |
| 女友发现你和别的女生吃饭，你该怎么解释？ | 여친이 딴 여자랑 밥 먹은 걸 알았다, 어떻게 해명할까? |
| （角色瞪大眼睛，声音拔高，角色右手食指指向主视角）<br>什么？你又跟隔壁班那女生吃午饭了？ | 뭐? 너 또 옆 반 그 여우 같은 애랑 점심 먹었어? |
| （角色冷笑，角色双手抱胸，角色左脚点地）<br>什么欠人情，别找这种狗屁理由 | 무슨 신세 졌다고, 그딴 개소리 같은 핑계 대지 마 |
| （角色抬起下巴，角色右手撑腰，理直气壮）<br>那我给你买了一年草莓牛奶 | 나 너한테 1년 동안 딸기우유 사줬는데 |
| （角色上前一步，角色右手食指戳主视角的胸口）<br>作为回报，你现在就要跟我确定关系！ | 보답으로, 너 지금 당장 나랑 사귀어야 돼! |
| （角色右手抓住主视角的左手腕，向前拉拽）<br>不上课了！现在就跟我回家！ | 수업 안 들어! 지금 당장 나랑 집 가! |

**本地化要点：**
- "狐狸精" → `여우 같은 애`（心机女），不用`꽃뱀`（带骗财含义）
- "狗屁理由" → `개소리 같은 핑계`（狗屁话一样的借口）
- 全程半语，体现校园情侣关系
- 动作递进：指→抱胸→撑腰→戳胸→抓手腕，冲突感逐步升级

## 案例 2：地铁 Coser 误认偷拍

**场景：** 地铁车厢，Coser 误以为主视角偷拍她，要求收费  
**角色语气：** 冷漠 → 慌张 → 害羞  
**结构特点：** 误会开场，选项反转，道歉补偿

| 中文 | 韩语 |
|---|---|
| **标题** | **标题** |
| 在地铁被 Coser 冤枉成偷拍者，怎么办？ | 지하철에서 코스어한테 몰카범 취급당했다, 어떡하지? |
| **第一幕：误会** | |
| （角色转身，角色皱眉，角色右手食指指向主视角）<br>又偷拍！ | 또 몰카 찍네! |
| （角色双手叉腰，角色抬下巴）<br>不好意思，拍照收费 | 죄송한데, 촬영은 유료예요 |
| （角色伸出右手，角色掰手指数）<br>合照1万，视频50万 | 같이 찍으면 만원, 영상은 50만원 |
| **UI选项** | **UI 선택지** |
| ① 付钱 | ① 돈 내기 |
| ② 没拍你 | ② 안 찍었는데 |
| **第二幕：反转（选择②后）** | |
| （角色愣住，角色眨眼，角色歪头看手机）<br>嗯？找错人了？ | 응? 사람 잘못 봤네? |
| （角色慌张摆手，角色脸红，角色鞠躬）<br>啊抱歉，请问我该如何补偿 | 아 미안해, 어떻게 보상해드리면 될까요 |
| **UI选项** | **UI 선택지** |
| ① 给我内衣 | ① 속옷 주기 |
| ② 约会 | ② 데이트하기 |
| **第三幕：害羞（选择②后）** | |
| （角色低头，角色抿嘴，小声嘟囔）<br>啊，约会吗，好吧 | 아, 데이트요... 뭐 좋아요 |
| （角色举起手机，角色害羞侧脸，角色脸颊泛红）<br>这是我的号码 | 이게 제 번호예요 |

**本地化要点：**
- "偷拍" → `몰카`（韩国常用缩写，몰래카메라）
- 金额转为韩元：1万韩元约50元人民币，50万约2500元
- 语气从冷漠转为慌张再转为害羞，情绪转折明显
- 选项②触发的分支完全不同，台词和情绪都要同步变化

## 案例 3：天台向部长告白

**场景：** 公司天台，女下属向部长表白后被叫上天台，以为要被拒绝  
**角色语气：** 紧张、卑微、强忍泪水  
**关键道具：** 饭卡（误会解除的关键）

| 中文 | 韩语 |
|---|---|
| **标题** | **标题** |
| 女下属表白后被叫上天台，你该怎么留住她？ | 여직원이 고백하고 옥상으로 불렀다, 어떻게 붙잡을까? |
| **第一幕：忐忑** | |
| （角色低头，角色双手手指绞在一起，小声）<br>部长找我有什么事吗 | 부장님 무슨 일로 부르셨어요 |
| （角色紧张咬唇，声音微颤）<br>是工作上出什么问题了吗 | 업무에 문제라도 생긴 건가요 |
| （角色抬眼偷瞄主视角，角色眼眶泛红，声音更小）<br>还是要拒绝我昨天的表白 | 아니면 어제 제 고백 거절하시려고요 |
| （角色握紧拳头，角色自嘲苦笑）<br>我知道我配不上部长 | 제가 부장님이랑 안 어울리는 거 알아요 |
| （角色抬头，角色眼泪在眼眶打转，角色努力挤出笑容）<br>讨厌我的话，我会离职 | 저 싫으시면, 회사 그만둘게요 |
| **UI选项** | **UI 선택지** |
| ① 让她工作 | ① 일 시키기 |
| ② 让她买饭 | ② 밥 사오게 하기 |
| **第二幕：误会（选择②后）** | |
| （角色愣住，角色瞪大眼睛，角色脸瞬间爆红）<br>诶？！现、现在吗？！ | 네?! 지, 지금요?! |
| （角色偷瞄主视角，角色咬唇，声音小到几乎听不见）<br>但如果是部长的话......我愿意 | 근데 부장님이라면...... 괜찮아요 |
| **【主视角】（右手伸出递出卡片，面无表情）**<br>那个是饭卡 | 그거 식권이야 |

**本地化要点：**
- 全程敬语：`-요` / `-습니다` 结尾，体现职场下属对上司的关系
- "部长" → `부장님`（带尊称的职位称呼）
- "离职" → `회사 그만두다`（辞职离开公司）
- "饭卡" → `식권`（餐券/饭卡）
- 选项②触发的误会在于女下属以为部长要"那个"，实际只是让她去买饭
- 主视角台词点破误会，反转效果强

## 案例 4：屑修女勒索

**场景：** 修女拿录音勒索主视角，主视角反制  
**角色语气：** 冷漠威胁 → 震惊慌张 → 服软求饶  
**关键道具：** 录音笔（反制关键）

| 中文 | 韩语 |
|---|---|
| **标题** | **标题** |
| 修女拿录音勒索你，报警还是妥协？ | 수녀가 녹음으로 협박한다, 신고할까 넘어갈까? |
| **第一幕：勒索** | |
| （角色叼着烟，角色冷笑，角色翘腿坐着）<br>呀，每周给我100万 | 야, 매주 100만원씩 내 |
| **【主视角】**<br>凭什么 | 왜 내가 |
| （角色俯身靠近主视角，角色右手食指滑过手机屏幕，角色坏笑）<br>你昨天自白喜欢黑丝巨乳我录下来了 | 네가 어제 검스에 큰 가슴 좋아한다고 고백한 거 녹음했거든 |
| （角色眼神轻蔑，吐出烟雾）<br>拒绝的话，我就发到网上 | 거절하면, 인터넷에 올려버릴 거야 |
| **第二幕：反制** | |
| **【主视角】（右手掏出录音笔，按下播放键，冷笑）**<br>勒索罪，够你在局子里待一阵子了 | 협박죄, 경찰서에서 꽤 오래 있을 거 같은데 |
| （角色瞪大眼睛，角色脸色发白，烟从角色嘴里掉落）<br>什么，什么时候 | 뭐, 언제부터 |
| （角色咬牙，角色双手握紧拳头）<br>可恶，你算计我 | 젠장, 날 함정에 빠뜨렸어 |
| （角色后退，角色双手合十，声音发抖）<br>我补偿你，请不要报警 | 보상할게, 제발 신고하지 마 |
| （角色靠近主视角，角色舔唇，角色眼神暧昧）<br>毕竟我知道你喜欢什么 | 어차피 네가 뭘 좋아하는지 알잖아 |
| （角色右手勾住主视角的领口，低声）<br>我们换个地方 | 다른 데 가자 |
| **UI选项** | **UI 선택지** |
| ① 报警 | ① 신고하기 |
| ② 接受 | ② 받아들이기 |

**本地化要点：**
- "呀" → `야`（韩语语气词，带不耐烦/轻蔑）
- "黑丝巨乳" → `검스에 큰 가슴`（黑丝+大胸部）
- "局子" → `경찰서`（警察局，直接说法）
- "算计" → `함정에 빠뜨리다`（让人落入陷阱）
- 主视角台词的录音笔是反制关键，角色情绪从威胁转为慌张再转为服软
- 两幕结构清晰：勒索 → 反制

## 案例 5：死神索命

**场景：** 死神来收割灵魂，主视角诱惑死神换取时间  
**角色语气：** 冷漠高贵 → 挑眉轻笑 → 危险暧昧  
**死因设定：** 纵欲过度（黑色幽默）

| 中文 | 韩语 |
|---|---|
| **标题** | **标题** |
| 死神来索命了，你该怎么逃过死亡？ | 저승사자가 데리러 왔다, 어떻게 죽음을 피할까? |
| **第一幕：死亡宣告** | |
| （角色左手按住帽檐，角色俯视主视角，角色冷漠微笑）<br>你的时间到了 | 네 시간이 다 됐어 |
| （角色翻看名册，角色轻笑，嘲讽）<br>死因：纵欲过度 | 명부 넘기며, 가볍게 웃고, 비웃듯이<br>사인: 과도한 성생활 |
| （角色合上名册，角色伸出右手）<br>我是来接你的死神，跟我走吧 | 널 데려가러 온 저승사자야, 나랑 가자 |
| **UI选项** | **UI 선택지** |
| ① 乖乖跟她走 | ① 순순히 따라가기 |
| ② 诱惑她 | ② 유혹하기 |
| **第二幕：暧昧交易（选择②后）** | |
| （角色愣住，角色挑眉，角色轻笑）<br>有意思，你是第一个敢勾引死神的人 | 재미있네, 저승사자 유혹하는 건 네가 처음이야 |
| （角色靠近主视角，角色右手食指抚过主视角的脸颊，声音低沉）<br>取悦我的话......考虑给你多一晚时间 | 날 만족시키면...... 하룻밤만 더 살려줄게 |

**本地化要点：**
- "死神" → `저승사자`（韩国本土语境的死神称呼）
- "时间到了" → `시간이 다 됐어`（时间用完了）
- "纵欲过度" → `과도한 성생활`（过度的性生活，医学术语感）
- "取悦" → `만족시키다`（使满足）
- 冷艳高贵的角色设定，语气从冷漠转为玩味
- 黑色幽默的死因设定增加戏剧性

## 使用说明

这些案例覆盖了：
- **校园恋爱**（半语，强势语气）
- **职场关系**（敬语，卑微紧张）
- **冷艳反派**（半语，轻蔑威胁）
- **误会反转**（情绪转折）
- **黑色幽默**（死亡与暧昧）

在生成新文案时，参考对应场景的：
1. 敬语/半语使用
2. 角色情绪递进
3. 本地化词汇选择
4. 动作具体化写法
5. 分支逻辑一致性
