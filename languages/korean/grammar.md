# 韩语语法与语气规则

韩语的敬语体系、语气特征和表达方式详细说明。

---

## 敬语体系层级

### 1. 격식체 (正式体)

**特征：**
- 最正式的表达方式
- 用于演讲、新闻、公文
- 短剧中较少使用（除非特殊场景）

**语尾：**
- `-습니다/ㅂ니다`（陈述）
- `-습니까/ㅂ니까`（疑问）
- `-십시오`（命令）

**示例：**
```
감사합니다（谢谢）
죄송합니다（对不起）
```

### 2. 비격식체 (非正式敬语)

**特征：**
- 日常最常用的敬语
- 礼貌但不过分拘谨
- 短剧中职场/服务场景常用

**语尾：**
- `-요`（陈述/疑问/命令）

**示例：**
```
좋아해요（我喜欢）
어디 가요?（去哪里？）
앉아요（请坐）
```

### 3. 반말 (半语)

**特征：**
- 亲密关系使用
- 可以表达强势、轻蔑或亲密
- 短剧中情侣/朋友/强势角色常用

**语尾：**
- `-어/아`（陈述）
- `-어?/아?`（疑问）
- `-어라/아라`（命令）

**示例：**
```
좋아해（我喜欢）
어디 가?（去哪里？）
앉아（坐）
```

## 敬语/半语切换规则

### 关系决定语体

| 关系 | 使用语体 | 示例场景 |
|---|---|---|
| 职场上司-下属 | 下属用敬语，上司用半语 | 部长对员工可以用半语 |
| 晚辈-长辈 | 晚辈用敬语，长辈用半语 | 侄女对叔叔用敬语 |
| 情侣 | 双方用半语 | 恋爱关系亲密 |
| 初次见面 | 双方用敬语 | 陌生人礼貌 |
| 强势-弱势 | 强势者可用半语 | 勒索者对受害者 |

### 角色一致性

- **同一角色在同一剧情中不能随意切换敬语/半语**
- 除非关系发生重大变化（从陌生到亲密、从尊重到轻蔑）

## 语气词与感叹词

### 疑问/质疑

| 韩语 | 中文 | 使用场景 |
|---|---|---|
| 뭐? | 什么？ | 半语，惊讶/质问 |
| 왜? | 为什么？ | 半语，质疑 |
| 응? | 嗯？ | 半语，疑惑 |
| 네? | 诶？ | 敬语，惊讶 |
| 진짜? | 真的？ | 半语，惊讶 |
| 정말요? | 真的吗？ | 敬语，惊讶 |

### 不满/愤怒

| 韩语 | 中文 | 使用场景 |
|---|---|---|
| 야 | 喂 | 半语，轻蔑/不耐烦 |
| 싫어 | 讨厌 | 半语，拒绝 |
| 싫은데요 | 不想... | 敬语，委婉拒绝 |
| 젠장 | 可恶 | 粗口，愤怒 |
| 제기랄 | 该死 | 粗口，懊恼 |

### 撒娇/暧昧

| 韩语 | 中文 | 使用场景 |
|---|---|---|
| 왜 그래... | 怎么了... | 半语，撒娇 |
| 싫은데... | 不想... | 半语，欲拒还迎 |
| 너무해... | 过分... | 半语，撒娇抱怨 |
| 그만해... | 够了... | 半语，羞涩制止 |

## 语尾变化规则

### -요 (敬语语尾)

**基本规则：**
- 动词词干 + `-어요/아요` → 简化为 `-요`

**示例：**
```
하다（做） → 해요
가다（去） → 가요
먹다（吃） → 먹어요
좋다（好） → 좋아요
```

### -어/아 (半语语尾)

**基本规则：**
- 动词词干 + `-어/아`

**示例：**
```
하다（做） → 해
가다（去） → 가
먹다（吃） → 먹어
좋다（好） → 좋아
```

### 疑问形式

**敬语疑问：**
- 语尾上扬 + `요`

**半语疑问：**
- 语尾上扬 + `?`

**示例：**
```
가요?（去吗？）- 敬语
가?（去吗？）- 半语
```

## 强势角色语气特征

### 冷艳反派

**语气特点：**
- 用半语
- 短促有力
- 多用嘲讽语气词

**示例：**
```
뭐야, 이거?（什么，这个？）
재미없는데?（没意思啊？）
꺼져（滚）
```

### 霸道女友

**语气特点：**
- 用半语
- 直接质问
- 带醋意

**示例：**
```
누구야, 저 여자?（谁啊，那个女人？）
설명해（解释）
거짓말하지 마（别撒谎）
```

---

## 害羞/卑微角色语气特征

### 职场下属

**语气特点：**
- 用敬语
- 语气犹豫
- 多用委婉表达

**示例：**
```
저기요...（那个...）
죄송한데요...（不好意思...）
괜찮으시다면...（如果方便的话...）
```

### 害羞告白

**语气特点：**
- 用敬语或半语（根据关系）
- 结巴、重复
- 声音小

**示例：**
```
저... 그... 좋아해요（我... 那个... 喜欢你）
말하고 싶었어요...（一直想说...）
```

## 命令/请求表达

### 敬语命令（请求）

**语尾：** `-세요`

**示例：**
```
앉으세요（请坐）
가세요（请走）
말씀하세요（请说）
```

### 半语命令

**语尾：** `-어라/아라` 或 `-어/아`

**示例：**
```
앉아（坐）
가（走）
말해（说）
```

### 强硬命令

**特征：** 语气短促，带威胁感

**示例：**
```
닥쳐（闭嘴）
꺼져（滚）
당장（马上）
```

## 语气强度对比

### 同一意思的不同强度

**"走开"的不同强度：**

| 强度 | 韩语 | 场景 |
|---|---|---|
| 礼貌 | 가세요 | 敬语，礼貌请求 |
| 普通 | 가 | 半语，普通命令 |
| 不耐烦 | 가라 | 半语，不耐烦 |
| 愤怒 | 꺼져 | 粗口，愤怒驱赶 |

**"为什么"的不同强度：**

| 强度 | 韩语 | 场景 |
|---|---|---|
| 礼貌 | 왜 그러세요? | 敬语，礼貌询问 |
| 普通 | 왜 그래? | 半语，普通询问 |
| 质问 | 왜? | 半语，质问 |
| 愤怒 | 왜 그러는 거야? | 半语，愤怒质问 |

## 语气与表演指示对应

### 示例1：强势角色

**表演指示：**
```
（角色冷笑，右手指向主视角，语气轻蔑）
```

**台词语气要求：**
- 用半语
- 短促有力
- 带嘲讽

**正确示例：**
```
뭐야, 너?（什么啊，你？）
```

**错误示例：**
```
❌ 당신은 누구세요?（您是谁？）← 太礼貌
```

### 示例2：害羞告白

**表演指示：**
```
（角色低头，双手绞在一起，声音很小）
```

**台词语气要求：**
- 用敬语
- 结巴、犹豫
- 语气柔和

**正确示例：**
```
저... 좋아해요...（我... 喜欢你...）
```

**错误示例：**
```
❌ 좋아해（喜欢）← 太直接，不符合害羞人设
```

## 常见错误

### 错误1：敬语/半语不符合关系

```
❌ 职场下属对上司用半语：
    야, 부장!（喂，部长！）
    
✅ 职场下属对上司用敬语：
    부장님!（部长！）
```

### 错误2：语气强度不符合情绪

```
❌ 愤怒场景用礼貌语气：
    저기요, 그만하시겠어요?（那个，您能停下吗？）
    
✅ 愤怒场景用强硬语气：
    그만해!（够了！）
```

### 错误3：同一角色语体不一致

```
❌ 第一幕用敬语，第三幕突然用半语（关系没变）：
    第一幕：좋아해요（喜欢您）
    第三幕：좋아해（喜欢你）
    
✅ 保持一致，或在关系变化时明确转换点
```
