# 剧情结构设计（全语言通用）

本文档定义短剧的核心剧情结构逻辑，适用于所有目标语言（韩语/日语/英语）。

---

## 结构类型判断

在开始写剧情前，先判断适用哪种结构：

> **角色主动勾引、主视角被动、本子/擦边向** → 用推拉结构，见 `core/push-pull-structure.md`（不走下方驯化检查）。

### 驯化结构适配检查

**开始写剧情前，先检查：**

```
□ 主视角有真实权力？（老板/看守/债主/掌握把柄）
□ 角色无法轻易离开？（合同/监狱/孤岛/经济依赖）
□ 需求符合马斯洛前三层？（生理/安全/社交）
□ 时间跨度够长？（≥3天）
```

**判断：**
- ✅ 全部满足 → 用驯化结构
- ⚠️ 1-2个× → 考虑简化或换结构
- ❌ 3个以上× → 不适合驯化，用失败结尾或反转

**需求层级示例：**
- ✅ 生理需求：不让洗澡、不给热水、不让睡觉（角色受不了）
- ✅ 安全需求：刑期长短、人身安全、经济损失
- ✅ 社交需求：不被孤立、保住面子、职场地位
- ❌ 伪需求：给零食、给化妆品、给特权（太轻，不成立）

## 驯化结构

### 核心逻辑

1. **三幕对应角色三个不同状态**（数值名称固定，只改变数值体现递进）
2. **每一幕的选项类型一致**（用户持续做同一动作）
3. **每一幕的时间跨度 ≥ 1天**
4. **掌控爽点**：角色非常重要的需求掌握在主视角手里

### 情绪递进

```
第一幕：抵抗期
- 角色状态：敌对、反抗、嚣张
- 数值：负值（如 -20）
- 选项：建立掌控权

第二幕：动摇期
- 角色状态：犹豫、软化、试探
- 数值：接近0或小正值（如 -10 或 +10）
- 选项：继续施压或给予奖励

第三幕：屈服期
- 角色状态：接受、依赖、顺从
- 数值：高正值（如 +90）
- 选项：巩固关系或最终选择
```

### 选项设计原则

- **每幕选项功能一致**：如果第一幕是"施压型选项"，三幕都应是施压型
- **强度递增但功能不变**：第一幕"不让洗澡"→ 第二幕"继续禁止洗澡"→ 第三幕"永久禁止洗澡"
- **避免混杂不同动作**：不要一幕是惩罚，一幕是奖励，会导致逻辑混乱

### 典型案例参考

- **惩罚洁癖女囚犯**（参考 references/korean/gold-dialogues-v1.2.md）
  - 单一需求：洗澡权
  - 三幕递进：反抗 → 动摇 → 屈服
  - 数值变化：-20 → -10 → 90

## 失败结尾结构

### 核心逻辑

**冲突 → 暧昧 → 失败**

### 情绪递进

```
第一幕：冲突期
- 角色状态：敌对/嚣张/挑衅
- 主视角：被动接受或尝试应对
- 选项：如何回应冲突

第二幕：暧昧期
- 角色状态：软化/试探/假暧昧
- 主视角：误以为有机会
- 选项：推进关系（包含陷阱选项）

第三幕：失败期
- 角色状态：反击/反转/嘲笑
- 主视角：因错误选择翻车
- 结果：主视角失败，角色获胜
```

### 选项设计原则

**正确选项特征：**
- 尊重角色意愿
- 给角色主动权
- 慢节奏推进

**错误选项特征（过激选项）：**
- 过于激进/强迫
- 忽视角色边界
- 看起来有吸引力但会翻车

**示例：**
```
第二幕，她说"换个地方"：
① 跟她走         （正确 - 尊重她的节奏）
② 按她在墙上     （错误 - 过激，触发反击）
```

### 典型案例参考

- **健身房辣妹反杀**（参考 references/korean/gold-dialogues-v1.2.md）
  - 第一幕：辣妹挑衅主视角
  - 第二幕：辣妹暧昧邀约
  - 第三幕：主视角选错被反杀

## 反转结构

### 核心逻辑

**被动 → 积累证据 → 反制**

### 情绪递进

```
第一幕：被动期
- 角色状态：强势/威胁/勒索
- 主视角：表面顺从，暗中准备
- 铺垫：留下伏笔（录音笔/摄像头等）

第二幕：试探期
- 角色状态：得寸进尺/继续威胁
- 主视角：继续伪装
- 铺垫：证据完整

第三幕：反制期
- 角色状态：被反击/慌乱/服软
- 主视角：亮出证据/掌控全局
- 结果：主视角反败为胜
```

### 关键设计点

- **伏笔必须自然**：第一幕的细节在第三幕揭晓
- **反转要有力量感**：主视角的反制手段必须彻底
- **角色表情剧烈变化**：从嚣张到慌乱的落差要大

### 典型案例参考

- **屑修女勒索**（参考 references/korean/gold-dialogues.md）
  - 第一幕：修女用偷拍视频勒索
  - 第二幕：主视角假装答应
  - 第三幕：主视角掏出录音笔反制

## 主视角说话时机

### 主视角该说话

- **反转时刻**：掏出录音笔、亮出把柄、揭晓真相
- **掌控宣言**："你不用洗澡了"、"从今天起你归我管"
- **揭晓真相**："那个是饭卡"、"录音已经上传"

**特征：**
- 有明确的台词内容
- 通常在第三幕或关键转折点
- 需要用【主视角】标注

### 主视角不说话

- **被动接受剧情**：角色独角戏，主视角只是观众
- **选择驱动剧情**：失败结尾类型，主视角通过选项行动
- **角色独角戏时**：角色自己推进剧情

**特征：**
- 不需要台词
- 通过选项表达意图
- 表演指示中没有【主视角】

## 三幕标准长度

### 台词数量

- **每幕台词**：≤3句
- **每句台词**：≤20字中文（韩语/日语）或≤15词（英语）

### 选项数量

- **第一幕**：3个选项（建立选择感）
- **第二幕**：3个选项（继续递进）
- **第三幕**：2个选项（收束剧情）

### 时间跨度

- **驯化结构**：每幕≥1天（第一天、第三天、一周后）
- **失败结尾**：时间可以较短（当天、第二天）
- **反转结构**：根据剧情需要灵活设定

## 疑难解答

### Q1：剧情逻辑太复杂，设定过重怎么办？
**A**：去掉多余背景。不需要"前女友"、"为什么进监狱"、"什么罪名"等设定。只保留核心：角色身份 + 单一需求 + 掌控手段。

### Q2：征服角色理由不成立怎么办？
**A**：检查需求是否符合马斯洛层级。"给零食"像养狗，改用生理/安全需求（不让洗澡、不给热水）。

### Q3：健身房/咖啡厅等开放场景怎么写驯化？
**A**：大部分开放场景不适合驯化结构，因为角色可以自由离开。要么：
- 增加掌控权设定（主视角是老板，可以吊销会员卡）
- 换成失败结尾结构（角色反杀主视角）

### Q4：什么时候用驯化，什么时候用失败结尾？
**A**：
- 驯化：封闭场景 + 主视角有真实权力 + 角色无法离开
- 失败结尾：开放场景 + 主视角权力弱 + 角色可以自由行动

### Q5：反转结构适合什么场景？
**A**：适合角色一开始占据主动权，但主视角有隐藏手段的场景。如勒索、威胁、陷害等。
