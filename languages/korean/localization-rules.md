# 韩语本地化规则

韩语短剧台词本地化的核心原则和规则。

---

## 核心本地化原则

### 优先级

```
韩国人自然会说的话 > 符合角色身份 > 保留中文原意 > 字面对应
```

### 示例

- "狐狸精" → `여우 같은 애`（心机女）
- "说到做到" → `행동으로 보여주다`（用行动展示）
- "部长" → `부장님`（带敬语）

---

## 敬语/半语系统

韩语的核心特征是严格的敬语体系，必须根据角色关系选择正确的语尾。

### 敬语（존댓말）

**使用场景：**
- 职场下属对上司
- 晚辈对长辈
- 初次见面
- 客服/服务人员对客户
- 害羞/卑微的角色

**语尾形式：**
- `-요`（日常敬语）
- `-습니다/ㅂ니다`（正式敬语）
- `-세요`（命令/请求）

**示例：**
```
좋아해요（我喜欢）
죄송합니다（对不起）
가세요（请走）
```

### 半语（반말）

**使用场景：**
- 情侣、朋友、同学
- 长辈对晚辈
- 强势角色对弱势角色
- 嚣张/不礼貌的角色

**语尾形式：**
- `-어/아`（陈述）
- `-지`（确认）
- `-어라/아라`（命令）

**示例：**
```
좋아해（我喜欢）
미안해（对不起）
가（走）
```

## 角色语气速查表

| 角色类型 | 敬语/半语 | 语气特点 | 表演特点 |
|---------|----------|---------|---------|
| 职场下属 | 敬语 `-요` | 小心翼翼、紧张、卑微 | 低头、手指绞在一起、咬唇 |
| 强势女友 | 半语 `-어` | 醋意、理直气壮、霸道 | 瞪眼、双手抱胸、戳胸口 |
| 冷艳反派 | 半语 | 嘲讽、威胁、轻蔑 | 冷笑、叼烟、翘腿、俯视 |
| 害羞暧昧 | 敬语/半语 | 结巴、声音小、欲拒还迎 | 低头、咬唇、脸红、偷瞄 |

## 台词长度与节奏

### 长度限制

- 每句台词：≤20字中文
- 每幕台词：≤3句

### 台词节奏

韩语台词应该：
- **短促有力**：删除冗余连接词
- **情绪集中**：一句话只表达一个情绪
- **自然停顿**：符合韩语口语节奏

**示例：**
```
✅ 뭐야, 이거?（什么，这个？）
✅ 왜 안 씻어?（为什么不洗澡？）
❌ 뭐야, 이게 대체 뭔데 나한테 이렇게 하는 거야?（太长）
```

## 职场称谓

韩国职场严格的上下级关系必须在称谓中体现。

| 中文 | 韩语 | 使用场景 |
|---|---|---|
| 部长 | `부장님` | 下属对部长（必须敬语） |
| 课长 | `과장님` | 下属对课长（必须敬语） |
| 科长 | `계장님` | 下属对科长（必须敬语） |
| 代理 | `대리님` | 下属对代理（必须敬语） |
| 社长 | `사장님` | 员工对老板（必须敬语） |

**注意：**
- 称谓必须带 `-님`（敬称）
- 下属对上司必须用敬语
- 上司对下属可以用半语

## 网络俚语与现代用语

韩国年轻人常用的网络词汇，增加真实感。

| 中文 | 韩语 | 使用场景 |
|---|---|---|
| 偷拍 | `몰카` | `몰래카메라` 缩写 |
| 过火/过头 | `오버` | 外来语，表示过分 |
| 老司机 | `베테랑` | 资深玩家 |
| 心机女 | `여우 같은 애` | 狐狸精本地化 |
| 装纯 | `꼬리 치는 애` | 到处勾搭的人 |

## 情感表达

### 愤怒/不满

```
젠장（可恶）
제기랄（该死）
싫다（讨厌）
```

### 惊讶

```
뭐?（什么？）
진짜?（真的？）
네?!（诶？！）
```

### 暧昧/撒娇

```
왜 그래...（怎么了...）
싫은데...（不想...）
너무해...（过分...）
```

## 文化适配案例

### 狐狸精/绿茶

**中文语境：**
- 狐狸精：勾引男人的女人
- 绿茶：装纯的女人

**韩语本地化：**
- `여우 같은 애`（像狐狸一样的人，心机女）
- `꼬리 치는 애`（摇尾巴的人，到处勾搭）
- `꽃뱀`（花蛇，骗财型，慎用）

### 开房

**中文语境：**
- 开房：去酒店

**韩语本地化：**
- `호텔 가기`（去酒店，UI选项用）
- `방 잡기`（订房间，口语化）

### 勒索/威胁

**中文语境：**
- 勒索罪

**韩语本地化：**
- `협박죄`（威胁罪，韩国法律术语）

## 金额换算参考

韩元与人民币购买力不同，不能机械换算。

| 韩元 | 人民币（约） | 使用场景 |
|---|---|---|
| 1만원 (1万) | 50-60元 | 小额，合照费用 |
| 10만원 (10万) | 500-600元 | 中等，约会、礼物 |
| 50만원 (50万) | 2500-3000元 | 较大，视频费用 |
| 100만원 (100万) | 5000-6000元 | 大额，勒索金额 |

**注意：**
- 1万韩元在韩国可以买一顿便饭
- 50万韩元是比较大的金额
- 根据剧情合理选择金额

## 禁忌与敏感词

### 敏感词和谐

动词用 ◯◯ 替代（至少两个圆圈）：
```
❌ 操她
✅ ◯◯她
```

### 不需要和谐的词

- 惩罚（`벌하다`）
- 殴打（`때리다`）
- 禁止（`금지하다`）

## 常见错误

### 错误1：敬语/半语混用

```
❌ （职场下属对上司）
    야, 뭐야?（喂，什么？）← 应该用敬语
    
✅ （职场下属对上司）
    저기요, 이게 뭐예요?（那个，这是什么？）
```

### 错误2：直译中文成语

```
❌ 说到做到 → 말한 대로 하다
✅ 说到做到 → 행동으로 보여주다（用行动展示）
```

### 错误3：职场称谓缺少敬称

```
❌ 부장（部长）
✅ 부장님（部长+敬称）
```

### 错误4：台词过长

```
❌ 왜 이렇게 늦게 오는 거야, 나 여기서 한참 기다렸잖아
✅ 왜 이렇게 늦어?（为什么这么晚？）
```
