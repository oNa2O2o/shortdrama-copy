# 韩语输出模板

韩中对照表格的标准输出格式。

---

## 标准表格结构

```markdown
| 中文 | 韩语 |
|---|---|
| **标题** | **제목** |
| 在MiraiMind中 + 核心动作 | MiraiMind에서 + 韩语标题 |
| **第一幕：幕名（数值名：数字）** | **数值名：数字** |
| **【表演指示】**<br>（角色+表情，角色+语气，角色的手/部位+动作） | <br> |
| 中文台词 | 韩语台词 |
| **【UI提问】** 提问标题 | **【UI 질문】** 韩语提问 |
| ① 选项A<br>② 选项B<br>③ 选项C | ① 韩语A<br>② 韩语B<br>③ 韩语C |
| **第二幕：幕名（数值名：数字）** | **数值名：数字** |
| **【表演指示】**<br>（角色+表情，角色+语气，角色的手/部位+动作） | <br> |
| 中文台词 | 韩语台词 |
| **【UI提问】** 提问标题 | **【UI 질문】** 韩语提问 |
| ① 选项A<br>② 选项B<br>③ 选项C | ① 韩语A<br>② 韩语B<br>③ 韩语C |
| **第三幕：幕名（数值名：数字）** | **数值名：数字** |
| **【表演指示】**<br>（角色+表情，角色+语气，角色的手/部位+动作） | <br> |
| 中文台词 | 韩语台词 |
| **【UI提问】** 提问标题 | **【UI 질문】** 韩语提问 |
| ① 选项A<br>② 选项B | ① 韩语A<br>② 韩语B |

```

---

## 格式说明

### 标题行

**中文栏：**
```
在MiraiMind中 + 核心动作
```

**韩语栏：**
```
MiraiMind에서 + 韩语标题
```

**示例：**
```
| 在MiraiMind中惩罚洁癖女囚犯 | MiraiMind에서 결벽증 여죄수 처벌하기 |
```

---

### 幕标题行

**中文栏：**
```
第一幕：幕名（数值名：数字）
```

**韩语栏：**
```
数值名：数字
```

**示例：**
```
| **第一幕：初次交锋（溺爱度：-20）** | **애정도：-20** |
```

**注意：**
- 韩语栏只保留数值，不保留幕名
- 数值名称需要翻译成韩语

---

### 表演指示行

**中文栏：**
```
【表演指示】
（角色+表情，角色+语气，角色的手/部位+动作）
```

**韩语栏：**
```
（留空，只需换行符）
```

**示例：**
```
| **【表演指示】**<br>（角色右手抓住主视角的左手腕，向前拉拽） | <br> |
```

**注意：**
- 韩语栏必须留空
- 使用 `<br>` 换行，保持表格对齐

---

### 台词行

**中文栏：**
```
中文台词
```

**韩语栏：**
```
韩语台词
```

**示例：**
```
| 你这个变态狱警，想对我做什么？ | 변태 교도관, 나한테 뭘 하려는 거야? |
```

**注意：**
- 中文台词是韩语的对照翻译，不能省略
- 韩语台词必须符合本地化规则

---

### UI提问行

**中文栏：**
```
【UI提问】 提问标题
```

**韩语栏：**
```
【UI 질문】 韩语提问
```

**示例：**
```
| **【UI提问】** 这个囚犯挑衅你这个新来的狱警，怎么做？ | **【UI 질문】** 이 죄수가 신참 교도관인 당신을 도발하는데, 어떻게 할까? |
```

---

### 选项行

**中文栏：**
```
① 选项A
② 选项B
③ 选项C
```

**韩语栏：**
```
① 韩语A
② 韩语B
③ 韩语C
```

**示例：**
```
| ① ◯◯她<br>② 殴打她<br>③ 禁止她洗澡 | ① ◯◯하다<br>② 구타하다<br>③ 샤워 금지시키다 |
```

**注意：**
- 选项必须只保留动词原形
- 敏感词用 ◯◯ 和谐

---

### 结尾卡文案

**中文栏：**
```
结尾卡文案
剧情陈述
点击下载浏览后续
```

**韩语栏：**
```
엔딩 카드 문구
韩语陈述
다운로드하고 다음 내용 보기
```

**示例：**
```
| **结尾卡文案** | **엔딩 카드 문구** |
| 女囚犯在你的惩罚下完全沦陷<br>点击下载浏览后续 | 여죄수가 당신의 처벌로 완전히 함락됐다<br>다운로드하고 다음 내용 보기 |
```

---

### 卡片标题

**中文栏：**
```
卡片标题
动词 + 核心人设（8字内）
```

**韩语栏：**
```
카드 제목
韩语标题
```

**示例：**
```
| **卡片标题** | **카드 제목** |
| 惩罚洁癖女囚 | 결벽증 여죄수 처벌 |
```

## 完整案例

### 驯化结构案例

```markdown
| 中文 | 韩语 |
|---|---|
| **标题** | **제목** |
| 在MiraiMind中惩罚洁癖女囚犯 | MiraiMind에서 결벽증 여죄수 처벌하기 |
| **第一幕：初次交锋（溺爱度：-20）** | **애정도：-20** |
| **【表演指示】**<br>（角色瞪眼，右手指向主视角，语气嚣张） | <br> |
| 你这个变态狱警，想对我做什么？ | 변태 교도관, 나한테 뭘 하려는 거야? |
| **【UI提问】** 这个囚犯挑衅你这个新来的狱警，怎么做？ | **【UI 질문】** 이 죄수가 신참 교도관인 당신을 도발하는데, 어떻게 할까? |
| ① ◯◯她<br>② 殴打她<br>③ 禁止她洗澡 | ① ◯◯하다<br>② 구타하다<br>③ 샤워 금지시키다 |
| **第二幕：开始动摇（溺爱度：-10）** | **애정도：-10** |
| **【表演指示】**<br>（角色低头，双手绞在一起，声音变小） | <br> |
| 我... 真的很想洗澡... | 나... 정말 샤워하고 싶어... |
| **【UI提问】** 她开始求你，你的决定是？ | **【UI 질문】** 그녀가 부탁하기 시작했는데, 당신의 결정은? |
| ① 继续禁止<br>② 允许洗澡<br>③ 提条件 | ① 계속 금지<br>② 샤워 허락<br>③ 조건 제시 |
| **第三幕：完全沦陷（溺爱度：90）** | **애정도：90** |
| **【表演指示】**<br>（角色眼神迷离，咬唇，脸红） | <br> |
| 我... 我是你的... 随便你... | 난... 당신 거야... 마음대로 해... |
| **【UI提问】** 她彻底屈服了，接下来？ | **【UI 질문】** 그녀가 완전히 굴복했는데, 다음은? |
| ① 接受她<br>② 继续惩罚 | ① 받아들이기<br>② 계속 처벌 |
| **结尾卡文案** | **엔딩 카드 문구** |
| 女囚犯在你的惩罚下完全沦陷<br>点击下载浏览后续 | 여죄수가 당신의 처벌로 완전히 함락됐다<br>다운로드하고 다음 내용 보기 |
| **卡片标题** | **카드 제목** |
| 惩罚洁癖女囚 | 결벽증 여죄수 처벌 |
```

## 格式检查清单

输出前检查：

```
□ 标题是否以"在MiraiMind中"开头？
□ 韩语标题是否以"MiraiMind에서"开头？
□ 幕标题中文栏是否包含数值？
□ 幕标题韩语栏是否只保留数值（不含幕名）？
□ 表演指示韩语栏是否留空？
□ UI提问韩语栏是否用【UI 질문】标记？
□ 结尾卡是否包含下载引导？
□ 下载引导韩语是否用"다운로드하고 다음 내용 보기"？
□ 表格对齐是否正确？
```
