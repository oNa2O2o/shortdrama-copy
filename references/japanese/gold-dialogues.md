## 案例1：吃醋女友质问（校园口语、强势语气）

### 剧情类型
冲突类型，强势女友质问主视角

### 本地化要点
- 使用常体（情侣关系）
- 女性强势语尾：`〜わよ`、`〜のよ`
- 直接质问语气

### 对照表格

| 中文 | 日语 |
|---|---|
| **标题** | **タイトル** |
| 在MiraiMind中应对吃醋女友的质问 | MiraiMindで嫉妬する彼女の質問に答える |
| **第一幕：质问开始（好感度：30）** | **好感度：30** |
| **【表演指示】**<br>（女友双手抱胸，瞪眼，语气强势） | <br> |
| 刚才那个女人是谁？ | さっきの女、誰? |
| 为什么她要跟你说话？ | 何であの子があなたと話してるのよ? |
| **【UI提问】** 女友开始吃醋质问，你怎么回应？ | **【UI質問】** 彼女が嫉妬して質問している。どう答える? |
| ① 解释<br>② 转移话题<br>③ 反问她 | ① 説明する<br>② 話題を変える<br>③ 逆に聞く |

### 本地化亮点

1. **女性强势语尾**
   - `誰?` 而非 `誰ですか?`（常体，更直接）
   - `〜のよ` 强调语气

2. **省略主语**
   - 不说 `あの女の人は誰ですか`
   - 直接说 `さっきの女、誰?`（更符合日语习惯）

3. **情侣关系用常体**
   - 全程不用敬体
   - 体现亲密关系

## 案例2：害羞告白（职场敬语、卑微语气）

### 剧情类型
告白类型，职场下属向上司告白

### 本地化要点
- 使用敬体（职场关系）
- 犹豫、结巴语气
- 谦逊表达

### 对照表格

| 中文 | 日语 |
|---|---|
| **标题** | **タイトル** |
| 在MiraiMind中向部长告白 | MiraiMindで部長に告白する |
| **第一幕：鼓起勇气（好感度：50）** | **好感度：50** |
| **【表演指示】**<br>（角色低头，双手绞在一起，声音很小） | <br> |
| 部长... 那个... | 部長... あの... |
| 我... 我一直... 喜欢您... | あたし... ずっと... 好きでした... |
| **【UI提问】** 下属向你告白，你的反应是？ | **【UI質問】** 部下があなたに告白した。どう反応する? |
| ① 接受<br>② 拒绝<br>③ 考虑一下 | ① 受け入れる<br>② 断る<br>③ 考える |

### 本地化亮点

1. **敬体使用**
   - `好きでした` 而非 `好きだった`（敬体过去式）
   - 体现职场上下级关系

2. **犹豫表达**
   - `あの...`（那个...）
   - `...` 省略号表现结巴

3. **女性自称**
   - 用 `あたし` 而非 `私`（更年轻、可爱）

## 案例3：冷艳反派勒索（嘲讽语气）

### 剧情类型
反转结构，冷艳角色勒索后被反制

### 本地化要点
- 使用常体（强势、轻蔑）
- 短促有力
- 冷嘲热讽

### 对照表格

| 中文 | 日语 |
|---|---|
| **标题** | **タイトル** |
| 在MiraiMind中反制勒索的女人 | MiraiMindで脅迫する女を逆襲する |
| **第一幕：勒索开始（警惕度：80）** | **警戒度：80** |
| **【表演指示】**<br>（角色冷笑，掏出手机，语气轻蔑） | <br> |
| 这个视频要是传出去，你就完了 | この動画が流出したら、あなた終わりね |
| 给我五十万日元 | 五十万円ちょうだい |
| **【UI提问】** 她用视频勒索你，怎么办？ | **【UI質問】** 彼女が動画であなたを脅迫している。どうする? |
| ① 报警<br>② 给钱<br>③ 假装答应 | ① 警察に通報<br>② 金を渡す<br>③ 答えたふりをする |
| **第二幕：反制揭晓（警惕度：10）** | **警戒度：10** |

1. **冷艳语气**
   - `終わりね` 带威胁感的女性语尾
   - `ちょうだい`（给我）带命令感

2. **常体体现强势**
   - 不用敬体，体现轻蔑和强势

3. **主视角反制**
   - 用常体 `録音したよ`
   - 体现掌控感

## 案例4：大小姐型角色（优雅语气）

### 剧情类型
驯化结构，大小姐从高傲到屈服

### 本地化要点
- 使用敬体但带大小姐语尾
- `〜ですわ`、`〜ざます`
- 优雅但高傲

### 对照表格

| 中文 | 日语 |
|---|---|
| **标题** | **タイトル** |
| 在MiraiMind中驯服高傲大小姐 | MiraiMindで高慢なお嬢様を調教する |
| **第一幕：高傲期（服从度：-20）** | **服従度：-20** |
| **【表演指示】**<br>（角色抬起下巴，俯视，语气高傲） | <br> |
| 你算什么东西，也配碰我？ | あなたなんて、私に触れる資格もありませんわ |
| **【UI提问】** 大小姐轻视你，怎么做？ | **【UI質問】** お嬢様があなたを見下している。どうする? |
| ① 惩罚她<br>② 无视她<br>③ 教育她 | ① 罰する<br>② 無視する<br>③ 教育する |
| **第二幕：动摇期（服从度：-10）** | **服従度：-10** |
| **【表演指示】**<br>（角色咬唇，语气不再那么强硬） | <br> |
| 我... 我不是故意的... | あたくし... わざとじゃありませんわ... |
| **第三幕：屈服期（服从度：90）** | **服従度：90** |
| **【表演指示】**<br>（角色低头，声音颤抖，完全失去高傲） | <br> |
| 我... 听您的... | あたくし... あなたに従います... |

### 本地化亮点

1. **大小姐语尾**
   - `〜ませんわ`（优雅的否定）
   - `あたくし`（大小姐自称）

2. **语气递进**
   - 第一幕：高傲（`〜ませんわ`）
   - 第二幕：动摇（`じゃありませんわ...`）
   - 第三幕：屈服（`従います...`）

3. **保持角色特色**
   - 即使屈服也用 `あたくし`
   - 不完全变成普通女性

## 案例5：关西腔角色（爽朗语气）

### 剧情类型
失败结尾，关西辣妹反杀主视角

### 本地化要点
- 使用关西腔
- 语尾 `〜やん`、`〜やで`、`〜ねん`
- 爽朗、直率

### 对照表格

| 中文 | 日语 |
|---|---|
| **标题** | **タイトル** |
| 在MiraiMind中被关西辣妹反杀 | MiraiMindで関西ギャルに逆襲される |
| **第一幕：挑衅期（好感度：10）** | **好感度：10** |
| **【表演指示】**<br>（角色双手叉腰，笑着挑衅） | <br> |
| 你一直看着我干嘛？ | ずっとウチ見てどないしたん? |
| 想搭讪就直说嘛 | ナンパしたいんやったら言いや |
| **【UI提问】** 关西辣妹挑衅你，怎么回应？ | **【UI質問】** 関西ギャルがあなたを挑発している。どう返す? |
| ① 搭讪<br>② 道歉<br>③ 反挑衅 | ① ナンパする<br>② 謝る<br>③ 逆に挑発 |
| **第二幕：暧昧期（好感度：50）** | **好感度：50** |
| **【表演指示】**<br>（角色靠近，暧昧微笑） | <br> |
| 你还挺有意思的嘛 | けっこう面白いやん |
| 要不要去卡拉OK？ | カラオケ行かへん? |
| **第三幕：反杀期（好感度：-70）** | **好感度：-70** |
| **【表演指示】**<br>（角色猛推主视角，大笑） | <br> |
| 骗你的！你以为我真喜欢你？ | 嘘やん! ウチがあんた好きやと思ったん? |
| 太搞笑了吧！ | めっちゃウケるわ! |

### 本地化亮点

1. **关西腔语尾**
   - `〜やん`（吧、呢）
   - `〜へん`（否定，相当于标准语的 `〜ない`）
   - `〜ねん`（强调）

2. **关西特有词汇**
   - `ウチ`（我，关西女性自称）
   - `どないしたん`（怎么了，相当于 `どうしたの`）
   - `めっちゃ`（非常，相当于 `すごく`）

3. **爽朗直率**
   - 关西腔给人爽朗、不拘束的感觉
   - 即使反杀也带幽默感

## 本地化技巧总结

### 1. 根据角色选择语体

- 职场下属 → 敬体
- 情侣朋友 → 常体
- 大小姐 → 敬体 + 特殊语尾
- 强势角色 → 常体 + 强势语尾

### 2. 女性语尾多样化

- 强势：`〜わよ`、`〜のよ`
- 可爱：`〜だよ`、`〜なの`
- 大小姐：`〜ですわ`
- 关西：`〜やん`、`〜やで`

### 3. 省略主语

日语习惯在上下文明确时省略主语：
- ❌ `あなたは誰ですか`
- ✅ `誰?`

### 4. 方言增加特色

- 关西腔：爽朗、搞笑
- 博多腔：可爱、温柔
- 标准语：中性、通用

### 5. 保持角色一致性

- 同一角色语体不变
- 语尾风格贯穿始终
- 即使情绪变化，核心人设不变

## 案例：未亡人雪女（推拉勾引结构·标准案例，2026-10-28 成品）

### 剧情类型
推拉结构（`core/push-pull-structure.md`）。角色主导，主视角（房东）被动。本子向，写到擦边前。

### 人设
丈夫去世3年，宅家不出门，表面消沉实则欲求不满。银蓝长发盘起、蓝眼、泪痣、白色高领针织衫+浅蓝开衫+深色裙+黑丝（按参考图，不穿丧服）。
**核心诡计**：「交不起房租」是借口，目的是体面地把房东引进屋。

| **【表演指示】**<br>（雪女侧坐在你对面，单手托腮，嘴角勾起坏笑，往下瞟一眼自己的腿再看你，身体慢慢前倾） | <br> |

| **结尾卡文案** | **结尾卡文案（日语）** |
| 房租只是借口，你才是她想要的<br>点击下载浏览后续 | 家賃は口実。欲しかったのは、あなた<br>ダウンロードして続きを見る |
| **卡片标题** | **卡片标题（日语）** |
| 未亡人雪女 | 未亡人雪女 |

不写【UI提问】：每幕最后一句都已经在问主视角。

### 踩过的坑（问题 → 怎么改）
- 每幕3句太满（「今日はお引き取りください」「玄関先で失礼しました」）→ 删掉功能句，用关门、擦眼角鞠躬交代
- 第三幕「家賃の代わりに…私じゃダメですか」直接提交易 → 改成试探问句「私に興味があるんですか？」
- 最后一题「受け入れる / 断る」没有代入感 → 改成主视角说了一半的话（表白 / 岔开话题 / 反驳）
- 单数值「渇望度 30/60/99」按幕平均涨 → 改成好感度（升）+ 理性（降），各由选项和台词触发
- 门口直接切到屋内 → 中间加一句转场字

## 案例：1年ぶりの彼（重逢·选项+弹幕+口播片尾，2026-10-26 成品）

### 剧情类型
深夜一年没见的他来敲门，主视角（女）让他进屋；男主痞帅自信、慢慢凑近；主视角只说开场和中段两三句。两个无提问标题的二选一选项，全程弹幕，片尾 AI 聊天口播。

### 开场 / 标题

| 中文 | 日语 |
|---|---|
| 分屏上：让他进来前 | 入れる前 |
| 分屏下：让他进来后 | 入れた後 |
| 让一年没见的他进屋的结果… | 1年ぶりの彼を部屋に入れた結果… |
| 数值：心动值 0→99（男主每句涨，不打满） | ドキドキ |

### 台词

| 中文 | 日语 |
|---|---|
| 女：进来吧 | 入って |
| 男：哇，好怀念。一年没见了吧 | うわ、なっつ。1年ぶりだよね |
| 男：一点都没变嘛… | 全然変わってないじゃん… |
| 女：那当然。哪会那么快变 | そりゃそうでしょ。すぐ変わるわけないじゃん |
| **【选项1】**赶他走 / **给他倒水**（默认选中，接后面推水杯画面） | 追い返す / 水を出す |

| 男：果然很可爱 | やっぱ可愛いね |

| 男：…我已经忍不住了 | …もう、我慢できないよ |
| **【选项2】**推开他 / 接受他（手指犹豫不点，留悬念） | 突き放す / 受け入れる |

### 踩过的坑（问题 → 怎么改）
- 标题用「元カレ」（前男友）是违规词 → 改「彼」
- 参考片尾「元カレに家に入れた」助词错、用户台词「帰える」错字 → 改「を」「帰る」
- 弹幕和选项只给了日语，用户看不懂 → 所有屏幕文字附中文
- 新写弹幕「ここで着てるのバレる」别扭却只标「建议换」没改 → 直接换成「まだ着てるの健気すぎ」
- 口播三句自己起草，被用户改成指定意思 → 口播先问用户要传达什么，再本地化

### 踩过的坑（问题 → 怎么改）

## 使用指南

1. **参考结构，不是内容**：学习情绪递进逻辑，不要直接套用台词
2. **提取语气特征**：学习如何用语尾表达不同人设
3. **注意文化差异**：日语的敬语系统比韩语更复杂
4. **方言慎用**：除非角色人设明确，否则用标准语
5. **独立创作**：根据角色图和剧情需求独立设计台词
