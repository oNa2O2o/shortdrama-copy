## 案例：惩罚洁癖女囚犯（三幕驯化完整版）

**场景：** 看守所，新入狱囚犯态度恶劣，主视角通过控制洗澡权进行驯化  
**核心需求：** 洗澡权（生理需求）  
**数值变化：** 服从度 -20 → -10 → 90  
**时间跨度：** 第一天 → 一周后 → 两周后

| 中文 | 韩语 |
|---|---|
| **标题** | **标题** |
| 在MM中惩罚洁癖女囚犯 | MM에서 결벽증 여자 재소자 징계하기 |
| **第一幕：挑衅（服从度：-20）** | **복종도：-20** |
| （角色接过囚服，角色抬眼看向主视角，角色皱眉）<br>你一直色眯眯盯着我看什么 | 계속 야한 눈으로 쳐다보는데 뭐야 |
| （角色双手抱胸，角色后退一步，角色皱眉）<br>我要洗澡，你的眼神脏死了 | 샤워 해야 되는데, 네 눈빛 더럽네 |
| （角色右脚踩在椅子上，角色右手食指指向地面，角色冷笑）<br>把我的脚舔干净，不然我举报你骚扰 | 내 발 깨끗하게 빨아, 안 그러면 성희롱으로 신고할 거야 |

| **第二幕：暴躁（一周后，服从度：-10）** | **복종도：-10** |
| （角色拍打铁门，角色声音拔高，角色瞪眼）<br>为什么又停水了？ | 왜 또 물이 안 나와? |
| （角色抓住铁门栏杆，角色用力摇晃，角色咬牙）<br>我已经一周没洗澡了 | 벌써 일주일째 못 씻었어 |
| （角色身体发抖，角色声音嘶哑，角色眼眶泛红）<br>受不了了，回答我！ | 못 참겠어, 대답해! |
| **UI选项** | **UI 선택지** |
| 她态度更加恶劣，怎么做？<br>① 嘲讽她 / ② ◯◯她 / ③ 禁止她洗澡 | 태도가 더 나빠졌다, 어떡하지?<br>① 비웃기 / ② ◯◯기 / ③ 샤워 금지 |
| **第三幕：臣服（两周后，服从度：90）** | **복종도：90** |
| （角色跪在铁门前，角色低头，角色声音颤抖）<br>对不起，之前是我态度不好 | 미안해, 전에 내 태도가 안 좋았어 |
| （角色双手合十，角色抬头看主视角，角色眼眶泛红）<br>你要我做什么都可以 | 네가 원하는 거 뭐든지 할게 |
| （角色贴近铁门，角色哽咽，角色眼泪滑落）<br>拜托了，请让我洗澡 | 제발, 샤워 좀 하게 해줘 |
| **UI选项** | **UI 선택지** |
| 她恳求你让她洗澡，怎么做？<br>① ◯◯她 / ② 禁止她洗澡 | 샤워하게 해달라고 애원한다, 어떡하지?<br>① ◯◯기 / ② 샤워 금지 |

## 本案例的关键特点

### 1. 设定极简
- **去掉多余背景**：没有"前女友"、"为什么进监狱"、"什么罪名"等设定
- **单一需求**：只聚焦洗澡权，理解成本为零
- **场景简单**：牢房门口，不需要"探视室"、"登记面谈"等复杂场景

### 2. 需求层级合理
- **生理需求**：洗澡是马斯洛需求金字塔的基础层
- **视觉变化**：第一幕干净 → 第二幕头发油腻 → 第三幕邋遢崩溃
- **说服力强**：两周不洗澡，任何人都受不了

### 3. 三幕驯化结构
- **选项重复**：每幕的选项类型一致，用户持续施压
- **时间跨度**：一天 → 一周 → 两周，让用户感知时间折磨
- **数值可视化**：服从度 -20 → -10 → 90，清晰呈现角色变化

### 4. 态度转变明显
- **第一幕**：嚣张挑衅，"把我的脚舔干净"
- **第二幕**：暴躁焦虑，"受不了了，回答我"
- **第三幕**：彻底屈服，"你要我做什么都可以"

### 5. 结尾卡设计
- **陈述+提问**：不用逗号分隔，分两行
- **卡片标题**：总结核心爽点，8字以内
- **钩子作用**：引导用户继续玩下去

---

## 使用场景

当用户要求创作"驯化"、"调教"、"征服"类型剧情时，参考此案例：
1. 确定角色的核心需求（生理/安全/社交层级）
2. 设计三幕结构，每幕选项相同
3. 标注数值变化，让用户看到掌控效果
4. 添加结尾卡，制造钩子

**复用模板：**
- 在MM中驯服高傲女上司（需求：升职机会）
- 在MM中调教刁蛮大小姐（需求：零花钱/自由）
- 在MM中征服冷艳女杀手（需求：人身安全）

## 案例：健身房辣妹反杀（失败结尾完整版）

**场景：** 健身房，嚣张辣妹抢器械，主视角选择过激导致失败  
**核心冲突：** 冲突 → 暧昧（假） → 反杀  
**失败触发点：** 第二幕选择"按她在墙上"（过激选项）

| 中文 | 韩语 |
|---|---|
| **标题** | **标题** |
| 在MM中被健身房辣妹反杀 | MM에서 헬스장 섹시녀한테 역관광 |
| **第一幕：冲突** | |
| （角色走向主视角正在用的器械，角色双手叉腰，角色冷笑）<br>这台我要用了，让开 | 이거 내가 쓸 거야, 비켜 |
| （角色右手指向旁边的跑步机，角色轻蔑）<br>你去那边跑步就行 | 너 저기 런닝머신이나 해 |
| （角色上前一步，角色右手推向主视角的肩膀）<br>听不懂人话吗 | 말 못 알아들어? |
| **UI选项** | **UI 선택지** |

| **第二幕：暧昧（选择②后）** | |
| （角色手腕被抓住，角色愣了一下，角色脸微红）<br>你... | 너... |
| （角色靠近主视角，角色抬眼看主视角，角色咬唇）<br>挺有种的嘛 | 배짱 좋네 |
| （角色空出的左手搭在主视角的肩上，角色舔唇，角色压低声音）<br>要不我们换个地方 | 아니면 다른 데 갈까 |

| （角色转身离开，角色头也不回）<br>恶心 | 역겹네 |

| 被辣妹反杀 | 섹시녀한테 역관광 |

## 本案例的关键特点

### 1. 失败结尾的情绪递进
- **第一幕：纯冲突**，角色完全嚣张敌对
- **第二幕：假暧昧**，角色突然软化并主动邀约（陷阱）
- **第三幕：反杀**，选择过激选项触发角色反击

### 2. 错误选项的设计
**正确选项：** "跟她走" - 尊重她的节奏，可能有后续发展
**错误选项：** "按她在墙上" - 过于激进，忽视边界，看起来有吸引力但会翻车

错误选项的特征：
- 看起来很诱人（直接进入肢体接触）
- 但违反了角色的意愿边界
- 角色的"邀约"是试探，不是真的同意被强迫

### 3. 主视角完全不说话
- 所有剧情通过角色台词和选项推进
- 主视角没有【主视角】台词
- 更适合失败结尾类型（主视角处于被动）

### 4. 反杀的合理性
- 第一幕已展示角色的强势人设
- 第二幕的"软化"是假象，是在钓鱼
- 第三幕的反击符合人设，不突兀

### 5. 结尾卡的失败版设计
- 陈述：你太着急了（指出失败原因）
- 提问：她再也不会理你了 / 要重试吗？（给用户重来的钩子）

---

## 使用场景

当用户要求创作"失败结尾"、"反杀"、"翻车"类型剧情，或场景不适合驯化时，参考此案例：

1. 确定冲突点：角色的什么行为激怒/挑战主视角
2. 设计假暧昧：角色突然软化，设置陷阱
3. 设计错误选项：看起来有吸引力但过激的选项
4. 反杀要符合人设：角色反击的方式要和第一幕的人设一致

**复用模板：**
- 在MM中被高冷女上司反杀（职场场景）
- 在MM中被傲娇大小姐反杀（校园场景）
- 在MM中被冷艳女杀手反杀（危险场景）

**关键：开放场景（健身房、咖啡厅、街头）更适合失败结尾，因为角色可以自由离开，主视角没有真正的掌控权。**
