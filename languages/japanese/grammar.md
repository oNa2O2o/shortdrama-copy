# 日语语法与语气规则

日语的敬语体系、语气特征和表达方式详细说明。

---

## 敬语体系层级

### 1. 丁寧語（礼貌语/敬体）

**特征：**
- 日常最常用的礼貌表达
- 保持距离但不过分拘谨
- 短剧中最常用

**语尾形式：**
- `です`（判断、状态）
- `ます`（动词）
- `でした`（过去判断）
- `ました`（过去动词）

**示例：**
```
好きです（我喜欢）
行きます（我去）
美しいです（很美）
食べました（吃了）
```

### 2. 普通體（常体）

**特征：**
- 亲密关系使用
- 日记、独白、自言自语
- 短剧中朋友/情侣常用

**语尾形式：**
- `だ`（判断）
- 动词原形（`する/行く`）
- `だった`（过去判断）
- 过去形（`した/行った`）

**示例：**
```
好きだ（我喜欢）
行く（我去）
美しい（很美）
食べた（吃了）
```

### 3. 尊敬語（尊敬语）

**特征：**
- 对上司、客户、长辈
- 抬高对方
- 短剧中职场场景使用

**特殊动词：**
```
いる → いらっしゃる（在）
行く → いらっしゃる（去）
来る → いらっしゃる（来）
食べる → 召し上がる（吃）
言う → おっしゃる（说）
```

**示例：**
```
社長がいらっしゃいます（社长在）
何を召し上がりますか（您吃什么）
```

### 4. 謙譲語（谦逊语）

**特征：**
- 贬低自己
- 对上司汇报时使用
- 短剧中较少使用

**特殊动词：**
```
いる → おる（在）
行く → 参る（去）
食べる → いただく（吃）
言う → 申し上げる（说）
```

**示例：**
```
私が参ります（我去）
いただきます（我吃）
```

## 敬体/常体切换规则

### 关系决定语体

| 关系 | 使用语体 | 示例场景 |
|---|---|---|
| 职场上司-下属 | 下属用敬体+尊敬语 | 下属对部长用 `です・ます` |
| 晚辈-长辈 | 晚辈用敬体 | 学生对老师用敬体 |
| 情侣 | 双方用常体 | 恋爱关系亲密 |
| 初次见面 | 双方用敬体 | 陌生人礼貌 |
| 朋友/同学 | 双方用常体 | 亲密关系 |

### 角色一致性

- **同一角色在同一剧情中不能随意切换敬体/常体**
- 除非关系发生重大变化（从陌生到亲密、从尊重到轻蔑）

## 女性语气特征

### 强势女性

**语尾特征：**
- `〜わよ`（断言）
- `〜のよ`（强调）
- `〜わね`（确认）
- `〜でしょ`（反问）

**示例：**
```
知ってるわよ（我知道）
違うのよ（不是那样的）
そうよね（是那样呢）
分かるでしょ?（明白吧？）
```

### 可爱型女性

**语尾特征：**
- `〜だよ`（轻快）
- `〜なの`（撒娇）
- `〜だもん`（任性）
- `〜ね`（温柔）

**示例：**
```
好きだよ（喜欢哦）
知らないの（不知道啦）
だって... だもん（因为... 嘛）
そうだね（是那样呢）
```

### 大小姐型

**语尾特征：**
- `〜ですわ`（优雅）
- `〜ざます`（老派）
- `〜てよ`（命令）
- `〜ですのよ`（强调）

**示例：**
```
素敵ですわ（真棒呢）
知りませんわ（不知道呢）
やってよ（做给我看）
違いますのよ（不是那样的）
```

### 害羞型女性

**语尾特征：**
- `〜です...`（犹豫）
- `〜けど...`（欲言又止）
- `〜かな...`（不确定）

**示例：**
```
好きです...（喜欢...）
言いたいんだけど...（想说但是...）
いいかな...（可以吗...）
```

## 男性语气特征

### 粗野型男性

**语尾特征：**
- `〜だぜ`（强势）
- `〜ぞ`（断言）
- `〜だろ`（反问）
- `〜じゃねえか`（粗鲁反问）

**示例：**
```
知ってるぜ（我知道）
行くぞ（走了）
そうだろ?（是吧？）
違うじゃねえか（不是吗）
```

### 礼貌型男性

**语尾特征：**
- `〜だよ`（温和）
- `〜だね`（确认）
- `〜かな`（思考）

**示例：**
```
そうだよ（是那样哦）
いいね（好呢）
どうかな（怎么样呢）
```

### 冷酷型男性

**语尾特征：**
- `〜だな`（冷淡）
- `〜か`（质问）
- 省略语尾（更冷）

**示例：**
```
そうだな（是那样啊）
分かったか（明白了吗）
知らん（不知道）
```

## 疑问形式

### 敬体疑问

**语尾上扬 + `か`（正式）或直接上扬（日常）**

**示例：**
```
行きますか?（去吗？）- 正式
行きます?（去吗？）- 日常
```

### 常体疑问

**语尾上扬**

**示例：**
```
行く?（去吗？）
好き?（喜欢吗？）
何?（什么？）
```

### 强烈疑问/反问

**语气词加重**

**示例：**
```
マジで?（真的？）
嘘でしょ?（骗人的吧？）
何それ?（什么啊？）
```

## 命令/请求表达

### 敬体请求

**语尾：** `〜てください`

**示例：**
```
座ってください（请坐）
行ってください（请去）
話してください（请说）
```

### 常体请求（温和）

**语尾：** `〜て`

**示例：**
```
座って（坐下）
行って（去吧）
話して（说吧）
```

### 常体命令（强硬）

**语尾：** `〜ろ/〜れ`（动词命令形）

**示例：**
```
座れ（坐下）
行け（去）
話せ（说）
```

### 粗暴命令

**语尾：** 省略或粗口

**示例：**
```
黙れ（闭嘴）
消えろ（消失）
どけ（让开）
```

## 方言语气特征

### 关西腔（大阪）

**特征：**
- 爽朗、直率、幽默
- 语尾用 `〜や`、`〜やん`、`〜やで`、`〜ねん`

**示例：**
```
知ってるやん（知道吧）
そうやで（是那样哦）
何してんねん（在干嘛）
好きやねん（喜欢啊）
```

**否定形：**
```
知らんで（不知道）
行かへん（不去）
```

### 博多腔（福冈）

**特征：**
- 可爱、柔和
- 语尾用 `〜と?`、`〜けん`、`〜ばい`

**示例：**
```
好きと?（喜欢吗？）
分からんけん（不知道啊）
そうばい（是那样啊）
```

### 东北腔

**特征：**
- 淳朴、憨厚
- 发音模糊、拉长

**示例：**
```
そうだべ（是那样吧）
知らねえ（不知道）
```

**注意：** 短剧中方言慎用，除非角色人设明确。

## 语气与情绪对应

### 愤怒

**语气特点：**
- 短促有力
- 命令形或粗口
- 省略助词

**示例：**
```
やめろ!（住手！）
黙れ!（闭嘴！）
うるさい!（吵死了！）
消えろ!（消失！）
```

### 撒娇

**语气特点：**
- 拉长音
- 女性语尾
- 语气柔和

**示例：**
```
やだ...（不要...）
もう...（真是的...）
ひどい...（过分...）
ねえ...（呐...）
```

### 惊讶

**语气特点：**
- 短促
- 语气上扬
- 重复

**示例：**
```
え?（诶？）
マジで?（真的？）
嘘?（骗人？）
何それ?（什么啊？）
```

### 害羞

**语气特点：**
- 声音小
- 犹豫、结巴
- 省略句尾

**示例：**
```
あの... その...（那个... 那个...）
好き... です...（喜欢... 您...）
言えない...（说不出...）
```

## 语气强度对比

### 同一意思的不同强度

**"走开"的不同强度：**

| 强度 | 日语 | 场景 |
|---|---|---|
| 礼貌 | 行ってください | 敬体，礼貌请求 |
| 普通 | 行って | 常体，普通请求 |
| 不耐烦 | 行けよ | 常体，不耐烦 |
| 愤怒 | 消えろ | 粗口，愤怒驱赶 |

**"为什么"的不同强度：**

| 强度 | 日语 | 场景 |
|---|---|---|
| 礼貌 | どうしてですか | 敬体，礼貌询问 |
| 普通 | なぜ? | 常体，普通询问 |
| 质问 | 何で? | 常体，质问 |
| 愤怒 | 何でだよ! | 常体，愤怒质问 |

## 语气与表演指示对应

### 示例1：强势女性

**表演指示：**
```
（角色冷笑，右手叉腰，语气强势）
```

**台词语气要求：**
- 用常体
- 女性强势语尾 `〜わよ/〜のよ`
- 短促有力

**正确示例：**
```
何よ、それ?（什么啊，那个？）
```

**错误示例：**
```
❌ それは何ですか?（那是什么？）← 太礼貌
```

### 示例2：害羞告白

**表演指示：**
```
（角色低头，双手绞在一起，声音很小）
```

**台词语气要求：**
- 用敬体（保持距离感）
- 犹豫、结巴
- 语气柔和

**正确示例：**
```
あの... 好きです...（那个... 喜欢您...）
```

**错误示例：**
```
❌ 好きだよ（喜欢哦）← 太直接，不符合害羞人设
```

## 常见错误

### 错误1：敬体/常体不符合关系

```
❌ 职场下属对上司用常体：
    知ってる（我知道）
    
✅ 职场下属对上司用敬体：
    知っています（我知道）
```

### 错误2：性别语尾混用

```
❌ 男性角色用女性语尾：
    知ってるわよ（我知道）
    
✅ 男性角色用中性或男性语尾：
    知ってるよ（我知道）
```

### 错误3：人称代词性别错误

```
❌ 女性角色用男性粗野自称：
    俺は知らない（我不知道）
    
✅ 女性角色用女性自称：
    あたしは知らない（我不知道）
```

### 错误4：同一角色语体不一致

```
❌ 第一幕用敬体，第三幕突然用常体（关系没变）：
    第一幕：好きです（喜欢您）
    第三幕：好きだ（喜欢你）
    
✅ 保持一致，或在关系变化时明确转换点
```

## 质量检查清单

写完日语台词后检查：

```
□ 敬体/常体是否符合角色关系？
□ 同一角色的语体是否一致？
□ 女性/男性语尾是否正确？
□ 人称代词是否符合性别和身份？
□ 语气强度是否符合情绪？
□ 方言使用是否符合人设？
□ 命令/请求形式是否正确？
□ 语气词是否自然？
```
