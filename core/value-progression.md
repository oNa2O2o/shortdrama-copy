# 数值变化规则（全语言通用）

本文档定义短剧中数值变化的标注规则，适用于所有目标语言（韩语/日语/英语）。

---

## 数值标注基本规则

### 核心原则

1. **数值名称开始确定后三幕不可更改**：第一幕定义为"好感度"，后续两幕必须继续用"好感度"
2. **只改变数字，不改变名称**：体现角色状态递进
3. **数值名称必须具体化**：不用"态度"、"关系"等模糊词
4. **数值必须符合剧情逻辑**：驯化结构用负→正，失败结尾可以用正→负

---

## 数值名称设计

### 好的数值名称

**特征：**
- 具体指向角色某个心理状态
- 易于理解数值变化含义
- 符合剧情类型

**常用数值名称：**

#### 驯化结构适用
- 溺爱度、羞耻度、沦陷度、依赖度
- 服从度、屈服度、驯化度、顺从度
- 好感度、信任度、依恋度

#### 失败结尾适用
- 好感度、兴趣度、暧昧度、警惕度
- 信任度、期待度、失望度

#### 冲突/反转适用
- 愤怒值、恐惧值、慌乱度、理智度
- 警惕度、怀疑度、戒备度

### 错误的数值名称

**问题：**
- 太模糊，不知道具体指什么
- 和剧情逻辑不匹配
- 数值名称前后不一致

**示例：**
```
❌ 态度                              ← 太模糊
❌ 关系                              ← 不具体
❌ 第一幕"好感度"→第二幕"信任度"   ← 名称改变了
```

## 数值变化幅度

### 驯化结构标准递进

```
第一幕：负值（抵抗期）
数值范围：-30 ~ -10
推荐：-20

第二幕：接近0或小正值（动摇期）
数值范围：-10 ~ +20
推荐：-10 或 +10

第三幕：高正值（屈服期）
数值范围：+80 ~ +100
推荐：+90
```

**示例：**
```
好感度：-20 → -10 → +90
服从度：-15 → +5 → +85
沦陷度：-25 → 0 → +95
```

### 失败结尾标准递进

```
第一幕：低值或负值（冲突期）
数值范围：-20 ~ +20
推荐：+10

第二幕：中等正值（暧昧期）
数值范围：+30 ~ +60
推荐：+50

第三幕：负值或极低值（失败期）
数值范围：-50 ~ -80
推荐：-70
```

**示例：**
```
好感度：+10 → +50 → -70
兴趣度：+20 → +60 → -80
信任度：+15 → +55 → -65
```

### 等待回复结构特殊递进

参考 `waiting-preset.md`，好感度从高正值递减：

```
第一幕：98
第二幕：85
第三幕：68
第四幕：45
第五幕：15
```

## 数值标注格式

### 标准格式

```
第一幕：幕名（数值名：数字）
第二幕：幕名（数值名：数字）
第三幕：幕名（数值名：数字）
```

### 正确示例

```
第一幕：初次交锋（溺爱度：-20）
第二幕：开始动摇（溺爱度：-10）
第三幕：完全沦陷（溺爱度：90）
```

### 错误示例

```
❌ 第一幕：初次交锋（好感度：-20）
   第二幕：开始动摇（信任度：-10）     ← 数值名称改变了
   
❌ 第一幕：初次交锋（态度：-20）       ← 名称太模糊
   
❌ 第一幕：初次交锋
   第二幕：开始动摇（好感度：-10）     ← 第一幕没标注数值
```

## 数值变化逻辑检查

### 驯化结构检查清单

写完数值后，检查：

```
□ 第一幕是负值？（角色在抵抗）
□ 第二幕接近0或小正值？（角色开始动摇）
□ 第三幕是高正值？（角色屈服/依赖）
□ 数值变化有合理的递进？（不能跳太快）
□ 数值名称三幕一致？
```

### 失败结尾检查清单

```
□ 第一幕是低值或负值？（角色不喜欢主视角）
□ 第二幕是中等正值？（角色开始有好感）
□ 第三幕是负值？（主视角选错，角色反感）
□ 数值变化符合"暧昧→翻车"逻辑？
□ 数值名称三幕一致？
```

## 数值与台词/选项的对应关系

### 数值必须反映角色状态

**第一幕：溺爱度 -20**
- 角色台词：敌对、反抗、嚣张
- 角色表情：瞪眼、冷笑、不屑
- 选项：施压型（禁止她洗澡、惩罚她）

**第二幕：溺爱度 -10**
- 角色台词：犹豫、试探、软化
- 角色表情：咬唇、低头、偷瞄
- 选项：继续施压或给予小奖励

**第三幕：溺爱度 +90**
- 角色台词：顺从、依赖、服软
- 角色表情：眼神迷离、脸红、撒娇
- 选项：巩固关系或最终选择

### 数值与台词不匹配的错误示例

```
❌ 第一幕：好感度 -20
   角色台词："我好喜欢你啊～"         ← 负值不会说喜欢
   
❌ 第三幕：溺爱度 +90
   角色台词："滚开！我恨你！"         ← 高正值不会说恨
```

## 数值范围参考

### 负值区间含义

| 数值范围 | 角色状态 | 典型台词语气 |
|---|---|---|
| -30 ~ -20 | 强烈反感/敌对 | "滚"、"变态"、"别碰我" |
| -19 ~ -10 | 轻度反感/犹豫 | "我不想..."、"为什么要..." |
| -9 ~ -1 | 即将转变 | "算了..."、"好吧..." |

### 正值区间含义

| 数值范围 | 角色状态 | 典型台词语气 |
|---|---|---|
| +1 ~ +20 | 初步好感 | "谢谢"、"你还不错" |
| +21 ~ +50 | 明显好感/暧昧 | "你很特别"、"我喜欢和你在一起" |
| +51 ~ +80 | 深度依赖/迷恋 | "我离不开你"、"只要你..." |
| +81 ~ +100 | 完全沦陷/屈服 | "我是你的"、"随便你..." |

## 特殊数值类型

### 双数值系统（高级用法）

某些复杂剧情可以使用两个数值：

```
第一幕：初次交锋（好感度：-20，警惕度：80）
第二幕：开始动摇（好感度：-10，警惕度：50）
第三幕：完全沦陷（好感度：90，警惕度：10）
```

**注意：**
- 双数值系统复杂度高，慎用
- 两个数值必须有明确的关联逻辑
- 通常一个升另一个降

### 非数字数值（不推荐）

某些情况下可以用状态词：

```
第一幕：初次交锋（态度：敌对）
第二幕：开始动摇（态度：中立）
第三幕：完全沦陷（态度：顺从）
```

**问题：**
- 缺少量化感
- 不如数字直观
- 除非有特殊理由，否则优先用数字

## 常见错误汇总

### 错误1：数值名称不一致

```
❌ 第一幕：初次交锋（好感度：-20）
   第二幕：开始动摇（喜欢度：-10）
   第三幕：完全沦陷（溺爱度：90）
```

### 错误2：数值变化不合理

```
❌ 第一幕：初次交锋（好感度：-20）
   第二幕：开始动摇（好感度：-18）     ← 变化太小
   第三幕：完全沦陷（好感度：+10）     ← 不符合"沦陷"
```

### 错误3：数值与剧情类型不匹配

```
❌ 驯化结构：
   第一幕：+50 → 第二幕：+70 → 第三幕：+90
   （驯化应该从负值开始）
```

### 错误4：数值名称太模糊

```
❌ 态度、状态、关系、感觉
✅ 好感度、溺爱度、服从度、依赖度
```
