# 选项设计原则（全语言通用）

本文档定义短剧选项的设计规则，适用于所有目标语言（韩语/日语/英语）。

---

## 选项基本格式

### 标准结构

```
【UI提问】提问标题
① 选项A
② 选项B
③ 选项C
```

### 核心规则

1. **提问必须有情境**：谁、做什么、怎么做？
2. **选项只保留动词原形**：不加主语、不加修饰词
3. **敏感词用 ◯◯ 和谐**：至少两个圆圈
4. **选项数量固定**：第一幕3个、第二幕3个、第三幕2个

---

## 提问设计

### 好的提问标题

**特征：**
- 明确当前情境
- 包含角色身份
- 说明角色的行为
- 暗示主视角面临的选择

**示例：**
```
✅ 这个囚犯挑衅你这个新来的狱警，怎么做？
✅ 健身房辣妹邀你去更衣室，你怎么回应？
✅ 部长在天台向你告白，你的决定是？
✅ 修女拿出偷拍视频勒索你，怎么办？
```

### 错误的提问标题

**问题：**
- 太空泛，没有具体情境
- 只有动作，没有角色身份
- 剧透了剧情走向

**示例：**
```
❌ 怎么做？                          ← 没有情境
❌ 接下来呢？                        ← 没有角色信息
❌ 你会选择接受她吗？                ← 剧透了"接受"这个选项
```

## 选项设计

### 只保留动词原形

**正确示例：**
```
① ◯◯她
② 殴打她
③ 禁止她洗澡
```

**错误示例：**
```
❌ ① 我要◯◯她                       ← 有主语
❌ ② 狠狠殴打她                      ← 有修饰词
❌ ③ 不让她洗澡直到她服软            ← 太长，有因果
```

### 选项功能分类

#### 施压型选项（驯化结构常用）
- 剥夺需求
- 增加惩罚
- 展示权力

**示例：**
```
① 禁止她洗澡
② 扣她工资
③ 单独关押她
```

#### 奖励型选项（驯化结构后期）
- 给予奖励
- 满足需求
- 释放善意

**示例：**
```
① 允许她洗澡
② 给她热水
③ 缩短她的刑期
```

#### 试探型选项（失败结尾常用）
- 推进关系
- 测试边界
- 增加亲密度

**示例：**
```
① 跟她走
② 搂住她的腰
③ 按她在墙上
```

#### 应对型选项（冲突场景）
- 回应挑衅
- 选择态度
- 决定行动

**示例：**
```
① 报警
② 接受
③ 反击
```

## 错误选项设计（失败结尾专用）

### 陷阱选项特征

**目标：**
- 看起来有吸引力
- 实际会导致翻车
- 符合玩家的冲动选择

**设计原则：**
1. **过激性**：超出当前关系阶段
2. **边界感**：忽视角色意愿
3. **诱惑性**：爽点明确但后果严重

### 正确选项 vs 错误选项对比

| 情境 | 正确选项（尊重） | 错误选项（过激） | 结果 |
|---|---|---|---|
| 她说"换个地方" | 跟她走 | 按她在墙上 | 翻车 |
| 她邀你去更衣室 | 跟她去 | 直接◯◯她 | 翻车 |
| 她说"你很特别" | 谢谢 | 搂住她 | 翻车 |

### 为什么错误选项有吸引力？

- **满足即时爽感**：主视角立即获得主动权
- **看起来更有攻击性**：符合"征服"心态
- **误判角色态度**：以为暧昧=可以进一步

## 选项数量规则

### 标准配置

```
第一幕：3个选项（建立选择感）
第二幕：3个选项（继续递进）
第三幕：2个选项（收束剧情）
```

### 为什么第三幕只有2个选项？

1. **剧情已经接近尾声**：不需要太多分支
2. **强化最终选择感**：二选一更有冲击力
3. **节省玩家时间**：避免过度选择疲劳

### 特殊情况

- **等待回复结构**：部分幕可能无UI选项（参考 waiting-preset.md）
- **单选题场景**：极少数情况下可以只有1个选项（强制选择）

## 敏感词和谐规则

### 基本原则

- 用 ◯◯ 替代敏感动词
- 至少两个圆圈
- 不要用其他符号（❌ ××、**、###）

### 常见敏感词和谐

| 原词 | 和谐后 |
|---|---|
| 操她 | ◯◯她 |
| 强迫她 | ◯◯她 |
| 玩弄她 | ◯◯她 |
| 调教她 | ◯◯她 |

### 不需要和谐的词

- 惩罚、殴打、禁止、拒绝
- 接受、跟随、答应、离开
- 反击、报警、威胁、勒索

## 选项设计检查清单

写完选项后，逐项检查：

```
□ 提问标题包含角色身份和情境？
□ 选项只保留动词原形，没有主语和修饰词？
□ 敏感词用 ◯◯ 和谐？
□ 选项数量符合标准（3-3-2）？
□ 失败结尾的错误选项有诱惑性吗？
□ 驯化结构的选项功能一致吗？
```

## 典型错误示例

### 错误1：选项太长

```
❌ ① 报警并把视频交给警察
✅ ① 报警
```

### 错误2：选项有主语

```
❌ ① 我接受她的勒索
✅ ① 接受
```

### 错误3：选项有修饰词

```
❌ ① 乖乖跟她走
✅ ① 跟她走
```

### 错误4：敏感词未和谐

```
❌ ① 操她
✅ ① ◯◯她
```

### 错误5：提问没有情境

```
❌ 【UI提问】怎么做？
✅ 【UI提问】这个囚犯挑衅你这个新来的狱警，怎么做？
```
