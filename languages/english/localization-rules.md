# 英语本地化规则

英语短剧台词本地化的核心原则和规则。

---

## 核心本地化原则

### 优先级

```
英语母语者自然会说的话 > 符合角色身份 > 保留中文原意 > 字面对应
```

### 示例

- "狐狸精" → `homewrecker`（破坏家庭的女人）
- "绿茶" → `fake innocent girl`（装纯女）
- "部长" → `Director` / `Manager`（无敬语系统，靠称谓）

---

## 语气层级系统

英语没有敬语体系，但有明确的语气层级（tone/register）。

### 1. Formal（正式）

**使用场景：**
- 职场正式场合
- 陌生人初次见面
- 商务沟通
- 正式文书

**特征：**
- 完整句子
- 避免缩写
- 使用礼貌用语（`please`, `would`, `could`）

**示例：**
```
I would appreciate if you could help me.
May I ask you a question?
I am sorry for the inconvenience.
```

### 2. Casual（随意）

**使用场景：**
- 朋友、同事间
- 日常对话
- 短剧中最常用

**特征：**
- 缩写（`gonna`, `wanna`, `kinda`）
- 短句
- 口语化

**示例：**
```
Wanna grab coffee?
I'm gonna go now.
That's kinda weird.
```

### 3. Intimate（亲密）

**使用场景：**
- 情侣
- 暧昧关系
- 亲密朋友

**特征：**
- 短句、省略
- 昵称
- 暧昧暗示

**示例：**
```
Come here...
Miss me?
You're mine.
```

### 4. Aggressive（攻击性）

**使用场景：**
- 冲突、威胁
- 愤怒、不满
- 强势角色

**特征：**
- 短促有力
- 命令句
- 粗口（委婉）

**示例：**
```
Back off.
Shut up.
Don't even try.
What the hell?
```

## 俚语与缩写

### 常用缩写

| 完整形式 | 缩写 | 使用场景 |
|---|---|---|
| going to | gonna | 日常口语 |
| want to | wanna | 日常口语 |
| kind of | kinda | 日常口语 |
| got to | gotta | 日常口语 |
| out of | outta | 日常口语 |
| let me | lemme | 日常口语 |
| give me | gimme | 日常口语 |

**示例：**
```
I'm gonna go.（我要走了）
Wanna come?（想来吗？）
That's kinda weird.（有点奇怪）
Gotta run.（得走了）
```

### 强调词

| 词汇 | 使用场景 | 强度 |
|---|---|---|
| literally | 强调真实性 | 高 |
| totally | 完全同意 | 中 |
| absolutely | 绝对 | 高 |
| seriously | 认真的 | 中 |
| definitely | 肯定 | 中 |

**示例：**
```
I literally saw it.（我真的看到了）
Totally agree.（完全同意）
Absolutely not.（绝对不行）
Seriously?（认真的？）
```

## 台词长度与节奏

### 长度限制

- 每句台词：≤15词（英语单词密度低）
- 每幕台词：≤3句

### 英语台词特点

- **短句打断**：多用短句反问和情绪词
- **重复强调**：重复关键词表达强烈情绪
- **省略主语**：口语化省略

**示例：**
```
✅ What? No way.（什么？不可能）
✅ Back off. Now.（退后。现在。）
❌ What do you think you're doing? That's not acceptable at all.（太长）
```

## 职场与身份

### 职场称谓

英语没有敬语系统，通过称谓和语气体现上下级：

| 中文 | 英语 | 使用场景 |
|---|---|---|
| 部长 | Director / Manager | 职场上司 |
| 课长 | Section Manager | 职场中层 |
| 老板 | Boss / Chief | 老板 |
| 同事 | Colleague | 同级 |
| 下属 | Subordinate / Staff | 下级 |

**注意：**
- 通常直接叫名字（如 "John"）或职位（如 "Director"）
- 下属对上司用 Formal 语气，但无需特殊敬语

## 文化适配案例

### 狐狸精/绿茶

**中文语境：**
- 狐狸精：勾引男人的女人
- 绿茶：装纯的女人

**英语本地化：**
- `homewrecker`（破坏家庭的女人）
- `seductress`（诱惑者）
- `fake innocent girl`（装纯女）
- `manipulative bitch`（心机婊，粗口）

### 开房

**中文语境：**
- 开房：去酒店

**英语本地化：**
- `go to a hotel`（去酒店）
- `get a room`（开房，暗示性强）
- `my place or yours?`（我家还是你家？更直接）

### 偷拍

**中文语境：**
- 偷拍

**英语本地化：**
- `creepshot`（偷拍）
- `secret recording`（偷录）
- `taking pictures without permission`（未经允许拍照）

## 情感表达

### 惊讶

```
What?（什么？）
Seriously?（认真的？）
No way.（不可能）
You're kidding.（你在开玩笑）
Are you serious?（你认真的？）
```

### 愤怒/不满

```
Damn it.（该死）
What the hell?（搞什么？）
Back off.（退后）
Shut up.（闭嘴）
I'm done.（我受够了）
```

### 暧昧/撒娇

```
Come on...（拜托...）
Don't be like that...（别这样...）
You're mean...（你好坏...）
Stop teasing...（别逗我...）
```

### 威胁

```
Watch it.（小心点）
Don't test me.（别试探我）
You'll regret this.（你会后悔的）
Back off, now.（退后，马上）
```

## 对话节奏特征

### 短句打断

英语对话多用短句打断，而非长篇独白：

**示例：**
```
A: I saw you with her.
B: What?
A: Don't lie.
B: I can explain.
A: Save it.
```

### 反问确认

用短反问确认或表达不信：

**示例：**
```
Seriously?（认真的？）
Really?（真的？）
You sure?（你确定？）
No way.（不可能）
```

### 情绪词

用单个情绪词表达反应：

**示例：**
```
Wow.（哇）
Damn.（该死）
Shit.（糟了）
Great.（真棒/真糟，取决于语气）
Perfect.（完美/真糟，取决于语气）
```

## 敏感词和谐

### 基本规则

用 ◯◯ 替代敏感动词（至少两个圆圈）

### 常见敏感词和谐

| 原词 | 和谐后 |
|---|---|
| fuck her | ◯◯ her |
| rape her | ◯◯ her |
| force her | ◯◯ her |

### 粗口委婉化

英语粗口可以用委婉表达：

| 粗口 | 委婉表达 |
|---|---|
| fuck | what the hell / damn |
| shit | crap / damn |
| bitch | jerk / witch |

## 常见错误

### 错误1：语气过于正式

```
❌ （朋友间对话）
    I would appreciate if you could come with me.
    
✅ （朋友间对话）
    Wanna come with me?
```

### 错误2：句子过长

```
❌ What do you think you're doing right now?
✅ What are you doing?
✅ What the hell?
```

### 错误3：缺少缩写

```
❌ I am going to go now.
✅ I'm gonna go now.
```

### 错误4：直译中文

```
❌ 狐狸精 → fox spirit
✅ 狐狸精 → homewrecker
```

## 质量检查清单

写完英语台词后检查：

```
□ 语气层级是否符合角色关系？
□ 是否使用了口语缩写（gonna, wanna）？
□ 台词长度是否≤15词？
□ 是否使用了英语俚语而非直译？
□ 敏感词是否用 ◯◯ 和谐？
□ UI提问标记是否用【UI Question】？
□ 是否用短句打断而非长篇独白？
□ 粗口是否委婉化？
```
