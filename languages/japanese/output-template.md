## 格式说明

### 标题行

> 新规则：默认写网感短句标题（如 `交不起房租是你的谎言 / 家賃が払えないなんて、嘘だろ`），见 `core/title-endcard.md`。下方旧模板仅在用户要求时使用。

**中文栏：**
```
在MiraiMind中 + 核心动作
```

**日语栏：**
```
MiraiMindで + 日语标题
```

**示例：**
```
| 在MiraiMind中惩罚洁癖女囚犯 | MiraiMindで潔癖症の女囚を罰する |
```

---

### 幕标题行

**中文栏：**
```
第一幕：幕名（数值名：数字）
```

**日语栏：**
```
数值名：数字
```

**示例：**
```
| **第一幕：初次交锋（好感度：-20）** | **好感度：-20** |
```

**注意：**
- 日语栏只保留数值，不保留幕名
- 数值名称需要翻译成日语

---

### 表演指示行

**中文栏：**
```
【表演指示】
（角色+表情，角色+语气，角色的手/部位+动作）
```

**日语栏：**
```
（留空，只需换行符）
```

**示例：**
```
| **【表演指示】**<br>（角色右手抓住主视角的左手腕，向前拉拽） | <br> |
```

**注意：**
- 日语栏必须留空
- 使用 `<br>` 换行，保持表格对齐

---

### 台词行

**中文栏：**
```
中文台词
```

**日语栏：**
```
日语台词
```

**示例：**
```
| 你这个变态狱警，想对我做什么？ | 変態刑務官、あたしに何するつもり? |
```

**注意：**
- 中文台词是日语的对照翻译，不能省略
- 日语台词必须符合本地化规则
- 注意敬体/常体选择
- 注意性别语尾

---

### UI提问行

**中文栏：**
```
【UI提问】 提问标题
```

**日语栏：**
```
【UI質問】 日语提问
```

**示例：**
```
| **【UI提问】** 这个囚犯挑衅你这个新来的狱警，怎么做？ | **【UI質問】** この囚人が新人刑務官のあなたを挑発している。どうする? |
```

---

### 选项行

**中文栏：**
```
① 选项A
② 选项B
③ 选项C
```

**日语栏：**
```
① 日语A
② 日语B
③ 日语C
```

**示例：**
```
| ① ◯◯她<br>② 殴打她<br>③ 禁止她洗澡 | ① ◯◯する<br>② 殴る<br>③ シャワーを禁止する |
```

**注意：**
- 选项必须只保留动词原形
- 敏感词用 ◯◯ 和谐

---

### 结尾卡文案

> 新规则：陈述改为「表面→真相」短句，如 `房租只是借口，你才是她想要的 / 家賃は口実。欲しかったのは、あなた`。

**中文栏：**
```
结尾卡文案
剧情陈述
点击下载浏览后续
```

**日语栏：**
```
エンディングカード
日语陈述
ダウンロードして続きを見る
```

**示例：**
```
| **结尾卡文案** | **エンディングカード** |
| 女囚犯在你的惩罚下完全沦陷<br>点击下载浏览后续 | 女囚があなたの罰で完全に堕ちた<br>ダウンロードして続きを見る |
```

---

### 卡片标题

> 新规则：直接写人设关键词，如 `未亡人雪女`。

**中文栏：**
```
卡片标题
动词 + 核心人设（8字内）
```

**日语栏：**
```
カードタイトル
日语标题
```

**示例：**
```
| **卡片标题** | **カードタイトル** |
| 惩罚洁癖女囚 | 潔癖症女囚を罰する |
```

```

□ 敬体/常体使用是否一致？

```

## 注意事项

### 敬体/常体一致性

同一角色在同一剧情中必须保持敬体或常体一致，除非关系发生明确变化。

**错误示例：**
```
❌ 第一幕：好きです（敬体）
   第三幕：好きだ（常体）← 没有关系变化
```

**正确示例：**
```
✅ 全程用敬体：好きです → まだ好きです → ずっと好きです
✅ 或在第二幕明确转换：好きです → 好きになった（关系变亲密）
```

### 性别语尾正确性

女性和男性的语尾不能混用。

**错误示例：**
```
❌ 女性角色：知ってるぜ（男性语尾）
❌ 男性角色：知ってるわよ（女性语尾）
```

**正确示例：**
```
✅ 女性角色：知ってるわよ
✅ 男性角色：知ってるぜ
```

### 人称代词性别正确性

**错误示例：**
```
❌ 女性角色：俺は知らない（男性自称）
❌ 男性角色：あたしは好き（女性自称）
```

**正确示例：**
```
✅ 女性角色：あたしは知らない
✅ 男性角色：俺は好きだ
```
