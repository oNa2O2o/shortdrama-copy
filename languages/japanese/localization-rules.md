# 日语本地化规则

日语短剧台词本地化的核心原则和规则。

---

## 核心本地化原则

### 优先级

```
日本人自然会说的话 > 符合角色身份 > 保留中文原意 > 字面对应
```

### 示例

- "狐狸精" → `小悪魔`（魅惑型女性）
- "绿茶" → `ぶりっ子`（装可爱、假纯）
- "部长" → `部長`（需要配合敬语）

---

## 敬语体系

日语的敬语系统比韩语更复杂，分为三个层次。

### 1. 丁寧語（礼貌语/敬体）

**使用场景：**
- 对陌生人、长辈、上司
- 正式场合
- 保持礼貌距离

**语尾形式：**
- `です`（判断）
- `ます`（动词）
- `ません`（否定）

**示例：**
```
好きです（我喜欢）
行きます（我去）
分かりません（不知道）
```

### 2. 普通體（常体）

**使用场景：**
- 对朋友、同学、晚辈
- 亲密关系
- 日记、自言自语

**语尾形式：**
- `だ`（判断）
- `する/行く`（动词原形）
- `ない`（否定）

**示例：**
```
好きだ（我喜欢）
行く（我去）
分からない（不知道）
```

### 3. 尊敬語与謙譲語

**尊敬语（对上司/客户）：**
- `いらっしゃる`（来/去/在）
- `召し上がる`（吃/喝）
- `おっしゃる`（说）

**谦逊语（自谦）：**
- `参る`（去/来）
- `いただく`（吃/喝）
- `申し上げる`（说）

**注意：** 短剧中尊敬语/谦逊语较少使用，除非特殊职场场景。

## 人称代词选择

### 第一人称（自称）

| 人称 | 使用者 | 语气特点 |
|---|---|---|
| 俺（おれ） | 男性 | 粗野、随意、朋友间 |
| 僕（ぼく） | 男性 | 礼貌、谦逊、年轻人 |
| 私（わたし） | 男女通用 | 正式、礼貌 |
| あたし | 女性 | 可爱、年轻女性 |
| わし | 老年男性 | 老派 |

### 第二人称（对方）

| 人称 | 关系 | 语气特点 |
|---|---|---|
| お前（おまえ） | 非常亲密或粗鲁 | 男性朋友间/轻蔑 |
| 君（きみ） | 亲密 | 男性对晚辈/女友 |
| あなた | 礼貌 | 正式场合 |
| 貴様（きさま） | 极度轻蔑 | 敌对、愤怒 |
| てめえ | 粗暴 | 打架、威胁 |

### 第三人称

通常用名字或"彼/彼女"，避免过多使用人称代词。

## 女性语气特征

### 强势女性语尾

```
〜わよ（断言）
〜のよ（强调）
〜わね（确认）
```

**示例：**
```
知ってるわよ（我知道）
違うのよ（不是那样的）
そうよね（是那样呢）
```

### 可爱型语尾

```
〜だよ（轻快）
〜なの（撒娇）
〜だもん（任性）
```

**示例：**
```
好きだよ（喜欢哦）
知らないの（不知道啦）
だって... だもん（因为... 嘛）
```

### 大小姐语尾

```
〜ですわ（优雅）
〜ざます（老派大小姐）
〜てよ（命令）
```

**示例：**
```
素敵ですわ（真棒呢）
知りませんわ（不知道呢）
やってよ（做给我看）
```

## 台词长度与节奏

### 长度限制

- 每句台词：≤20字中文
- 每幕台词：≤3句

### 日语台词特点

- **短句为主**：日语比中文更简洁
- **省略主语**：上下文明确时省略
- **情绪在语尾**：语尾变化表达情绪

**示例：**
```
✅ 何それ?（什么啊？）
✅ 知らない（不知道）
❌ それは一体何なのか、私には全然分からないんだけど（太长）
```

## 文化适配案例

### 狐狸精/绿茶

**中文语境：**
- 狐狸精：勾引男人的女人
- 绿茶：装纯的女人

**日语本地化：**
- `小悪魔`（小恶魔，魅惑型女性）
- `ぶりっ子`（装可爱、假纯）
- `あざとい女`（心机女）

### 职场称谓

**中文语境：**
- 部长、课长

**日语本地化：**
- `部長`（需要敬语）
- `課長`（需要敬语）
- 称呼时加`さん`：部長さん

### 偷拍

**中文语境：**
- 偷拍

**日语本地化：**
- `盗撮`（盗摄，严重犯罪）
- `隠し撮り`（偷拍）

## 方言变体

### 关西腔（大阪）

**特征：**
- 爽朗、直率、搞笑
- 语尾用 `〜や`、`〜やん`、`〜やで`

**示例：**
```
知ってるやん（知道吧）
そうやで（是那样哦）
何してんねん（在干嘛）
```

### 博多腔（福冈）

**特征：**
- 可爱、柔和
- 语尾用 `〜と?`、`〜けん`

**示例：**
```
好きと?（喜欢吗？）
分からんけん（不知道啊）
```

### 东北腔

**特征：**
- 淳朴、憨厚
- 发音模糊

**注意：** 短剧中方言慎用，除非角色人设明确。

## 情感表达

### 惊讶

```
え?（诶？）
マジで?（真的？）
嘘でしょ?（骗人的吧？）
何それ?（什么啊？）
```

### 愤怒/不满

```
やめて（住手）
うるさい（吵死了）
黙れ（闭嘴）
最悪（最差劲）
```

### 撒娇/暧昧

```
やだ...（不要...）
もう...（真是的...）
ひどい...（过分...）
ずるい...（狡猾...）
```

## 敏感词和谐

### 基本规则

用 ◯◯ 替代敏感动词（至少两个圆圈）

### 常见敏感词和谐

| 原词 | 和谐后 |
|---|---|
| 犯す | ◯◯する |
| やる | ◯◯する |
| 襲う | ◯◯する |

## 输出格式规范

### UI提问标记

```
【UI質問】
```

### 下载引导

```
ダウンロードして続きを見る
```

### 标题格式

默认写网感信息流短句，不强制带 MiraiMind（详见 `core/title-endcard.md`）：

```
家賃が払えないなんて、嘘だろ
未亡人3年目、もう我慢できない
```

本子向可借鉴 AV/同人标题语感（「〜だろ」「〜だけ」「◯◯レス」），敏感词用 ◯ 屏蔽。

### 未亡人/人妻语气

- 丁寧語为底：`お引き取りください`、`お茶でも、いかがですか？`、`すみません、玄関先で失礼しました`
- 提到亡夫：`主人`（对外）、`あの人`（怀念）
- 勾引阶段转为带调侃的半敬语：`さっきから…脚ばっかり見てますよね？`、`私じゃ、ダメですか？`
- 禁止书面修辞腔（❌ `凍えてしまいますわよ。あなたが。`）

## 常见错误

### 错误1：敬体/常体混用

```
❌ （朋友间对话）
    好きです（我喜欢）← 太正式
    
✅ （朋友间对话）
    好きだよ（我喜欢哦）
```

### 错误2：人称代词选择错误

```
❌ （男性粗鲁角色用礼貌自称）
    私は知らない（我不知道）
    
✅ （男性粗鲁角色用粗野自称）
    俺は知らねえ（我不知道）
```

### 错误3：女性语尾用在男性身上

```
❌ （男性角色）
    知ってるわよ（我知道）← 女性语尾
    
✅ （男性角色）
    知ってるよ（我知道）
```

### 错误4：直译中文

```
❌ 狐狸精 → 狐の精
✅ 狐狸精 → 小悪魔
```

## 质量检查清单

写完日语台词后检查：

```
□ 敬体/常体是否符合角色关系？
□ 人称代词是否符合角色性别/性格？
□ 女性语尾是否符合人设？
□ 台词长度是否≤20字中文？
□ 是否使用了日本俚语而非直译？
□ 敏感词是否用 ◯◯ 和谐？
□ UI提问标记是否用【UI質問】？
□ 方言使用是否符合人设？
```
